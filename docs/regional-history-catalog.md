# 2019–2022 区域赛目录补齐

2026-10-10。两消费工程沿用共同的规范题目 ID，独立部署，不增加运行时依赖。保留已有 2023–2025 年 33 场、426 题，新增 42 场、528 题，总计 75 场、954 题。延期比赛按届次对应赛季归档，例如 2021 年举行的第 45 届昆明/银川仍为 2020 赛季。

题序来自 RankLand 原榜单 SRK，辅以 QOJ 历史分类页及 Codeforces 官方 Gym 列表。2019 厦门旧榜单没有结构化题列，采用 QOJ 分类明确列出的 A–L。2019 香港、2020 澳门采用官方 Gym 和 QOJ 分类共同确认题数。排除邀请赛、女生/高职专场、热身及总决赛；RankLand 的 `ccpc2021hangzhou` 中文标题实际为广州站，作为重复数据排除。

逐场来源、题序、原榜单内容 SHA-256 和映射状态见 [regional_history_sources.json](../src/qq_cf_bot/catalog/regional_history_sources.json)。已确认 Gym 的比赛保存 CF 别名；牛客赛题接口提供规范 problemId 和题名。无法读取题名时显示明确的“比赛名 · 题序”，不生成虚构题名。

CF Bot 进一步核对 QOJ 单题页字母和同场官方 Gym 题名，历史题目中 488 题已有平台映射。2019 ICPC 沈阳、南昌和 2022 ICPC 合肥的 39 题，以及 2020 CCPC 秦皇岛 C，保留完整题序但平台题号待核验。秦皇岛 Gym 102769 的官方题单缺少 C，不能生成不存在的别名。对应题目 `aliases: []`、`mapping_status: pending`，校验器只允许有原榜单来源的显式待映射项。QOJ 题号未凭连续编号猜测；题名未核实相同的跨平台镜像不合并。

现场榜单映射与线上平台映射分开：已确认现场 AC 能按比赛及字母进入区域赛进度，即使该题暂时没有线上题号。旧的暂存现场 ID 在重新同步同一参赛 UUID 时替换，不追加重复证据；现有线上提交保持原样，已核验平台别名与现场记录按题合并。2018 及各年总决赛继续显示现场历史，未纳入这次区域赛目录。

CF Bot 已按正式队赛时通过数及金银铜牌分界离线生成历史评级：新增 406 题，合计 832 题；其余 122 题缺少完整校准依据，明确保留未评级。构建覆盖全部目录，逐场记录榜单来源或未评级原因，网站不触发刷新。详见 [离线评级校准](regional-rating-calibration.md)。OJ Wall 全部年份均不显示 rating。
