## 网页阅读与整场下载

进入 `/regionals`，在赛站名称下点击 **下载题解 Markdown · 已收录数/总题数**，即可下载 UTF-8 整场合集。文件按原题号排列，包含目录、完整详解、来源、官方 PDF 页码和校验说明；缺题保留原题号与待补原因。下载接口 `GET /api/regionals/editorials.md?contest=<比赛ID>` 无需登录。

登录后点击单题，可以按需要查看 **先学什么**、三条 **渐进提示** 或 **完整题解**。学习入口给出具体知识顺序和自检问题；正文解释核心观察、推导、正确性、复杂度、实现边界与易错点。只有主动点击才返回对应内容，切题会收起题解。阅读记录按用户保存，下载与阅读均不会计为口胡通过或代码 AC。

全部内容从工程内读取，阅读和下载不调用模型，也不需要实时访问 QOJ。官方附件的访问权限仍由原站决定。

## 官方来源与内容文件

[版本清单](../src/qq_cf_bot/catalog/regional_editorials.json) 逐题登记 Markdown 路径、版本、官方来源、对应 PDF 实际页码、学习入口、三条提示及适用校验报告。`sources` 中保留 QOJ 题单、出题方页面和可用的 UCup 附件镜像；官方 PDF 本身未复制进发行包。

[正文目录](../src/qq_cf_bot/catalog/editorials/) 按年份和赛站保存。扩写以正式题面为准，遇到讲义笔误或略写的边界会在正文解释；补充的推导、例子和代码思路是本工程独立组织的内容，不代表出题方原文。

本批来源包括 THUSAA、SUA 以及 QOJ/UCup 比赛附件中的出题方讲义。2025 上海还对照了 THUSAA 公开仓库的正式题面和 accepted 标程。各场的作者、URL、附件哈希和核验时间以清单记录为准。

## 验证与维护

每篇正文都有对应的 `regional_editorial_validation*.json` 报告，记录 Markdown SHA-256、独立检查方法和通过数量。验证包括小规模穷举、与直接模拟或精确有理数模型对拍、交互协议模拟、真实构造检查以及几何边界检查。报告说明适用范围；这些检查不能视为在线 AC 或完整的极限性能验证。涉及 NTT、复杂数据结构或大规模构造时，要特别查看正文与报告中尚未验证的实现范围。

相关脚本位于 `scripts/validate_*editorials.py`，另有南京 2025 高尔夫与几何构造的专项脚本。通常可使用 `--report <报告路径>` 重跑对应验证；部分专项脚本需要 NumPy，Python 建议 3.10+。

发布前运行：

```bash
PYTHONPATH=src:tests python3 -m unittest test_regional_editorials test_regional
python3 scripts/validate_regional_catalog.py
```

接口测试会逐篇检查正文哈希与校验报告，并覆盖学习入口、提示、鉴权、CSRF、阅读记录隔离、HTML 过滤、整场附件、部分收录占位和个人训练状态不变。测试中的部分收录场景使用独立夹具，不依赖真实赛站一直缺题。

继续补题时，先核实正式题单与官方来源，再逐题扩写和独立验证。未完成或验证失败的题目保留待补，不登记为可读正文。打包配置已包含 `catalog/editorials/*/*.md`，服务随发行包加载，无需运行时生成或手动导入数据库。
