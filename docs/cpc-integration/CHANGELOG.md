v4 开发记录：三工程各自新增可选联动模块；cf-bot 保留现有同步和口胡数据。开发时使用独立副本，补丁预检后已写回三个本地工程，保留原有未提交改动。三数据库合同测试覆盖用户隔离、认领/榜单撤销、团队账号、失效连接码、错误信源、不完整快照和搬库后 ID/关联保持，并通过真实本地 HTTP 检查。上线状态和最终验证见运维说明，不把临时数据库测试视为生产榜单已导入。

v4.1 开发记录（2026-10-09）：应追加需求，在 DLUT CPC 管理后台增加“成员认证”，支持待审核/已通过/已拒绝/已撤销筛选、核验材料与审核历史、批准/拒绝/撤销二次确认。网页复用原管理员会话、CSRF 与同源检查，调用与 CLI 相同的审核方法；拒绝重复或过期审核，审核者不能由浏览器伪造。没有新增数据库模式、服务间权限或跨站管理员接口，旧版 v4 快照保留。
