# I · Bingo

## 先学什么

依次学习组合数、容斥、按最大元素计数、多项式卷积与NTT。先实现O(N²)的最大值贡献表，再用卷积加速。这里N=nm<=2×10^5，模数998244353；同值元素仍按原下标区分，共计N!种打乱方式。

## 把所有行列的最小值变成子集最大值

一行或一列的完成阈值是其中元素的最大值；整张表的最小bingo整数，就是全部n+m条行列阈值中的最小值。使用恒等式

```text
min(values) = sum(非空子集T) (-1)^(|T|-1) * max(T)
```

它可由对任意阈值做普通容斥得到。若选x行、y列，其覆盖格子数是c=m*x+n*y-x*y。被选行列的最大阈值，等于这c个格子中的元素最大值。因此所有选法只需要按c查询同一张表。

设H[c]为固定c个位置中最大值，在全部N!种排列下的总和。最终答案为

```text
sum(x=0..n,y=0..m,x+y>0)
  (-1)^(x+y-1) * C(n,x)*C(m,y) * H[m*x+n*y-x*y]
```

枚举数量(n+1)(m+1)=O(N)，不会因n,m分别大而变成N²。

## 求H[c]：按排序后的最后一个下标计数

将a从小到大排序，编号1..N。把同值元素按任意固定下标顺序打破平局。若选中位置里的最大排序下标为i，必须选a[i]，再从前i-1个选c-1个。选完以后，c个元素可排列c!种，其余元素可排列(N-c)!种。

```text
H[c] = c!*(N-c)! * sum(i=c..N) a[i]*C(i-1,c-1)
```

同值并不造成重复：每份带下标的排列恰有一个最大的排序下标，而它的数值就是需要的最大值。

## 一次卷积计算所有c

令s=i-1，r=c-1，拆组合数得到

```text
H[c] = c*(N-c)! * sum(s=r..N-1) a[s+1]*s!/(s-r)!
```

定义A[s]=a[s+1]*fact[s]，反转得到AR[j]=A[N-1-j]；定义B[t]=invFact[t]。计算C=AR*B，则

```text
H[c] = c * fact[N-c] * C[N-c]  (mod 998244353)
```

检查下标：卷积位置N-1-r中，AR的下标N-1-s与B的下标s-r相加正好得到它。不要把结果读成C[c]。

用NTT实现卷积，长度补到至少2N-1的2次幂。最大N=200000时需要524288，不能只补到覆盖N。阶乘和逆阶乘预处理到N即可。

## 自检与复杂度

H[N]=max(a)*N!，H[1]=sum(a)*(N-1)!。n=1或m=1时，总会有一个单格列或行，因此最终答案应为min(a)*N!。全数组都为v时，答案同样是v*N!。这些性质可以同时检查容斥符号、卷积反转和阶乘。

总时间O(N log N)，空间O(N)。乘法使用64位中间值，负的容斥项及时归一化。工程枚举小网格全部排列核对最终答案，并使用朴素卷积核对系数；未把这项校验宣称为已经测过NTT的最大长度实现。
