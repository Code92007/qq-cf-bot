# I · A Brand New Geometric Problem

## 先学什么

先学习整数因数分解、乘积分拆、分组背包与区间最小值查询。题目的高维几何只是包装：删除一个维度就是删一个数，扩展一个维度就是添加一个正整数，目标是让多重集合的和为S、积为M。

## 固定最终集合后，最少操作如何计算

n<=100000，S、M以及初始数值都至多10^10。设初始数字v出现cnt[v]次，最终出现take[v]次。应该保留二者能匹配的min(cnt[v],take[v])个，其他旧数删除，缺少的新数添加。因此总操作数为

```text
n + 最终元素数 - 2*sum_v min(cnt[v],take[v])。
```

把n理解为先删除全部旧元素的基线：最终选择c个值为v的元素，增量费用就是c-2*min(cnt[v],c)。这个增量可以为负，表示保留旧元素省下删除和重加两次操作；DP不能把负值当成“不存在”。

M的非约数不可能保留在最终集合里，但仍包含在基线n中。

## 把1拿出来：它只负责补足总和

最终所有大于1的因子按非降顺序写为x1,...,xt，乘积必须为M。若它们总和s>S，无效；否则最终1的数量被唯一确定为q=S-s。

最终费用为

```text
n + [非1因子的增量费用] + q-2*min(cnt[1],q)。
```

因此不必搜索1的数量。M=1时没有任何非1因子，答案直接为n+S-2*min(cnt[1],S)。S>=1保证最终集合非空。

一个直观但慢的算法是枚举M的所有无序乘积分拆，再套上式。为了处理因数很多的M，官方将因子按大小分成DP与搜索两部分。

## 小因子分组背包

取阈值B，官方给出的实践取值约500。小因子范围是2<=v<B且v整除M。先枚举M的全部约数并编号；DP的乘积状态只能是这些约数。

处理若干种小因子后，dp[d][s]表示选中小因子的乘积为d、和为s时，最小增量费用。初态dp[1][0]=0，其余不可达。

对每种v，枚举选择数量c>=0，要求d*v^c仍整除M，然后转移

```text
dp_new[d*v^c][s+c*v]
  =min(dp_new[...],dp_old[d][s]+c-2*min(cnt[v],c))。
```

这是按“值”分组的背包，必须由旧层转到新层，避免把同一种值分两次计算保留数量。c最多log2 M；可以逐次乘v并用除法检查，避免乘积溢出。

任何乘积不超过M的非1因子总数都不超过H=floor(log2 M)，所以小因子总和不超过W=(B-1)*H。再截断到S即可。只记录可达的(d,s)能明显节省实际内存；若用稠密数组，只保留相邻两层，空间O(约数个数*W)。

## 大因子递增搜索，和小因子DP拼接

大因子都至少B。B=500且M<=10^10时，最多选3个，因为500^4>10^10。因此可以DFS枚举非降的大因子列表：状态为剩余乘积rem、下一因子下界last、已选大因子和sumLarge、费用costLarge。

在每个状态，都可以停止枚举大因子，把剩余乘积rem交给小因子DP；也可以选择任意v>=max(B,last)且v整除rem，递归到rem/v。取v后若sumLarge+v>S即可剪枝。允许v=rem，代表最后一个大因子。

选择第c个相同的大因子v时，边际费用为-1（c<=cnt[v]，保留一个旧元素），否则为+1（需要新增）。因为列表非降，相同值一定连续，维护当前值已选数量即可，不能每次都当成第一个出现的v。

每个最终非1多重集合都唯一拆成小因子部分和递增大因子部分，因此这种枚举不漏、不重。

## 不要每个搜索节点重新扫描全部DP和

固定DFS状态，令R=S-sumLarge。需要在dp[rem][s]里找s<=R，使

```text
dp[rem][s] + (R-s)-2*min(cnt[1],R-s)
```

最小。设c1=cnt[1]，分成两段：

- 若s<=R-c1，1的需求至少c1，表达式为(dp[s]-s)+R-2*c1。
- 若R-c1<=s<=R，1的需求不超过c1，表达式为(dp[s]+s)-R。

对每个乘积rem，把可达s排序。第一段预处理dp[s]-s的前缀最小值；第二段对dp[s]+s建RMQ或线段树。用二分定位两个区间后，O(log W)或O(log W)+O(1)得到最小值。边界s=R-c1可重复参与两段，二者数值相同。

若没有可达s落在范围里，此DFS状态不能组成答案。所有状态都失败才输出-1。

## 例子与正确性

初始[1,2]，S=5、M=6。分拆[2,3]的和已经是5，无需1，保留2、删除1、添加3，共2次。按基线公式：n=2，选择已有2费用-1，选择新3费用+1，1费用0，总计2。

费用公式逐种数独立计算保留/删除/添加次数，必然最优；1的数量由总和唯一确定；小因子DP精确枚举每种数量，大因子DFS枚举其余无序因子；最后的两段查询只是同一费用函数的代数改写。因此算法得到全局最小操作数。

## 复杂度与实现边界

枚举约数O(sqrt(M))。记D为约数个数、W为小因子和上界、E为DP中实际枚举的“乘积状态、因子、使用数量”转移数，稠密转移时间O(E*W)，滚动空间O(D*W)；稀疏存储按实际可达和计数。大因子搜索深度至多3，其节点数取决于M的因数结构，每个节点的拼接查询O(log W)。这是官方采用大小因子分治而非直接全分拆搜索的原因。

B=500是官方经验参数，不是所有机器上的性能保证；若自行实现，应关注DP可达状态数、内存布局与乘积转移预计算。当前独立验证覆盖分治与费用查询的正确性，未进行5秒时限下的极限性能认证。S与答案都可能超过32位，使用64位；不可达值使用足够大的INF，所有乘法先判断是否会超过M。
