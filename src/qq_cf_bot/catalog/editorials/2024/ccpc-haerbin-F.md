# F · 1D Galaxy

## 先学什么

先学习并查集、双向链表、优先队列和离线查询，再学习事件驱动模拟：物体在两次相遇之间沿已知轨迹运动，直接跳到下一次相遇。本题更难的部分是证明需要处理的事件不多。建议先写 O(n²T) 的逐秒模拟器，特别保留负权测试，再理解下面的状态与摊还分析。

## 题意与真正困难的地方

n 颗星球的坐标和权重均在 [-10^9,10^9]，权重可以为负，初始坐标也可以重复。每个整数时刻，所有星球同时根据严格位于自己左右两侧的总权重决定下一秒移动：右侧更重则向右一步，左侧更重则向左一步，相等则不动。同坐标星球不计入任何一侧。星球可以互相穿过。

n,q<=10^5，每次询问某颗星球在 t<=10^9 时的位置，因此不能逐秒模拟。下面展开官方讲义的事件模拟思路，并补充负权下交换后一起平移的情况，以及同一时刻多次接触的处理。

## 重合后永远一起走，穿过则未必

已经重合的星球看到的左右权重完全相同，下一步也相同，归纳可知永远不会再分开。因此用并查集把它们合并成一个“点团”，权重取总和，保留原星球到代表元的映射。

设总权重为 W，一个点团的权重为 w，严格位于它左边的权重和为 L，则右边为 W-L-w，其速度为

```text
v = sign(W - 2*L - w)，取值为 -1、0、1。
```

只要没有点团从它身边穿过或与它重合，L 和 w 都不变，速度就是常数。远处的点团互相合并、交换，仍在同一侧，不影响这里的权重和。

但穿过不能直接做并查集合并。例如三颗星球为

```text
坐标     -100     0     1
权重        5    -4     6
```

第一步位置变成 -99、1、0。后两颗交换后，第二步变成 0、-1，随后一起向左移动，直到遇到外面的星球。它们既没有重合，也没有一直在原来的两个位置之间交换。忽略这个负权情况会得到错误算法。

## 相邻交换之后只有哪几种可能

考虑位于 x、x+1 的相邻点团，左团权重为 a，右团为 b；令 Δ 为这两团之外“右侧总权重减左侧总权重”。交换前速度分别为

```text
左团：sign(Δ+b)
右团：sign(Δ-a)。
```

发生穿越意味着它们分别向右、向左，因此 -b<Δ<a，特别是 a+b>0。交换后，左边放的是 b，右边放的是 a，新速度为

```text
左团 b：sign(Δ+a)
右团 a：sign(Δ-b)。
```

两个 sign 内部的数相差 a+b>0，所以左团速度不小于右团速度：它们不会向两边分开。具体只有三类后续：

1. 左边向右、右边向左：下一秒交换回来。由于外部权重没变，此后两种排列不断重复。
2. 两边都向左，或都向右：相距 1 一起平移，直到外部点团接触它们。
3. 一个静止、另一个朝它移动：下一秒真正重合。

两边同时静止不可能，因为那将要求 Δ+a=Δ-b=0，从而 a+b=0。

第一类可以压缩为一个“周期团”：两端位置固定为 x、x+1，保存两个并查集代表元和建立时刻，查询位置只看时间差的奇偶性。第二类不必增加新的复杂结构，保留两个普通点团和各自的直线轨迹即可；它们之间不会再产生事件，直到外部接触。第三类正常安排下一秒的重合事件。

压缩周期团时必须验证两种排列都向内运动。若当前左、右权重为 a、b，则完整条件是

```text
sign(Δ+b)=+1，sign(Δ-a)=-1，
sign(Δ+a)=+1，sign(Δ-b)=-1。
```

不能只验证第一行。这个条件也等价于 a、b 都为正且 |Δ|<min(a,b)。周期团中的两点不是真的重合，两个并查集代表元必须分别保留。

## 需要维护的状态

把所有点团、周期团按坐标排列，用双向链表维护邻居。每个状态保存：

- 不再复用的编号，以及是否仍有效。
- 建立时刻 t0、左端坐标 x、区间整体速度 v。
- 一个代表元，或周期团的两个代表元。
- 建立时严格在整个状态左侧的权重和 L，以及链表前驱、后继。

普通点团在 t 时的位置为 x+v*(t-t0)，其左右端点相同。周期团的整体速度为 0，始终占据 x、x+1；建立时在左边的代表元，于 t 时位于 x+((t-t0) mod 2)，另一个则相反。

用 owner[root] 找到代表元所属的当前状态。周期团外面的点团只会看到这个周期团的总权重，因为它始终占据相邻的两个整数坐标，外面不存在一个整数位置能插在两端之间。因此压缩不会改变外部运动。

## 怎样预测下一次接触

当前时刻为 t，两个相邻状态 A、B 的区间仍严格分离。令

```text
d = B.left(t) - A.right(t) > 0
c = A.velocity - B.velocity。
```

若 c<=0，它们不会在轨迹保持不变时相遇；否则下一次需要处理的整数时刻为

```text
t + ceil(d/c)。
```

这里“接触”包括端点重合，也包括两个普通点团一步穿越。比如相距 3、速度为 +1 和 -1，下一事件是两秒后，此时已经交换顺序，不能只寻找坐标相等。

将预测事件 `(时刻,A编号,B编号)` 放入最小堆。取出时检查两个状态仍有效，且 A 的后继仍是 B；否则丢弃。每次替换状态都分配新编号，所以不需要修改堆中的旧记录，也不必猜测旧速度是否还有效。

## 同一时刻必须按旧轨迹一起落位

这是实现中最容易写错的部分。某个事件发生在 T，不能先更新两个点团的速度，然后让同一时刻的其他点团使用新速度移动。所有星球到 T 的位置，都必须来自各自事件之前的轨迹。

处理取出的相邻状态 A、B 时：

1. 按旧轨迹算出它们在 T 的占据区间，取两个区间的并作为当前范围 [lo,hi]。
2. 查看旧链表中范围左侧的相邻状态。如果其右端在 T 满足 right(T)>=lo，就一并取入，并扩大范围。右侧类似，若 left(T)<=hi 就取入。反复扩展到两侧都严格分离。
3. 把取入状态在 T 的实际点团全部取出。普通状态给出一个点；周期状态按奇偶性给出两个点。然后才让这些旧状态失效。
4. 按实际坐标排序，同坐标的代表元全部并查集合并，不能因它们在旧链表中不相邻而漏掉重合。
5. 从取入范围原先最左状态的 L 开始，扫描新点团，按 `sign(W-2*L-w)` 计算速度；每经过一个点团就给 L 加上它的权重。
6. 找出满足完整双向条件的相邻周期对，其余保留普通点团。把新状态接回链表，更新 owner，并为新状态之间及两侧边界重新安排事件。

这个扩展不是把相距很远的同时事件混成一团，而是收齐在本次移动后区间相交、次序反转的整个局部范围。同刻但相互分离的事件可以依次处理：一侧范围的总权重没有改变，不会改变另一范围的旧轨迹。

例如六颗星球初始在 0、1、2、3、4、5，权重依次为 1、1、10、10、1、1。中间两颗构成周期团。第一步六颗的位置为 1、2、3、2、3、4：周期团两端同时被不同侧的外部点团碰到。必须先按奇偶性确定周期团两颗星球的位置，再分别合并坐标 2 和 3 上的点，不能只更新先从堆里弹出的一侧。

新状态之间仍严格分离，所以新安排的接触时刻一定大于 T。已有的另一个 T 时刻事件，要么因旧状态失效被丢弃，要么属于另一个独立范围。回答 T 时刻查询前，将堆内所有有效且时间不超过 T 的事件处理完即可。

## 为什么事件只有 O(n) 个

真正重合会减少点团数量，总共至多 n-1 次。周期团与外部接触时也必然发生真正重合：它同时占据连续两个整数位置，外部点团每秒最多走一步，无法越过整个区间而不落在其中一个位置上。因此，周期团被拆开、重建的次数可以由真正重合支付。

还需要控制负权造成的普通穿越。想象在一次穿越后相邻的两个点团之间画一条“粘连边”。这条边只是证明工具，不需要真的存到代码里。前面的分类说明：它们要么下一秒重合，要么立即被压缩为周期团，要么以相同速度保持距离 1。

对于最后一种，粘连关系不可能无代价地被别的点团打破。以两个点团都向左走为例，它们的位置为 x、x+1，下一步为 x-1、x。右侧点团每秒最多向左一步，追不上右端；只能左侧点团接触它们：

- 若左侧第三团静止，最早接触时原左端直接与它重合。
- 若左侧第三团向右，并恰好与原左端交换位置，它走到原左端的旧位置；此时原右端也向左走到了同一位置，所以第三团与原右端重合。
- 左侧第三团也向左则无法缩短距离。更远的团必须先经过最近邻，不能跳过这一论证。

两个点团同向右移动时完全对称。若考虑原本就相邻且共同静止的点团，任何外部点团也只能先与某一端真正重合。总之，粘连边在没有真正重合时不会被破坏，且外部左右权重也不会变化。

每次新的普通穿越建立一条这样的边；当前边数不超过相邻关系数，即 O(n)。一次真正合并若涉及 k 个点团，最多破坏 O(k) 条已有邻接边，而所有真正合并的 k 之和为 O(n)：每次 k>=2，且每次至少减少 k-1 个点团。因此，能被反复打破、重新建立的边也只有 O(n) 条，普通穿越总数为 O(n)。周期内部无限次交换已用奇偶性压缩。

事件扩展中被取出的状态，要么参加重合或穿越，要么是同时被触及的周期状态；按上述变化一起计费，总处理状态数为 O(n)。每个新状态只产生常数个邻接事件，堆中包括失效记录在内也只有 O(n) 条。这里不能用“每次交换就合并”来证明复杂度，因为那在负权情况下不成立。

## 离线查询、正确性与复杂度

把询问按 t 从小到大排序。处理所有不晚于 t 的事件后，找到原星球的并查集代表元，再通过 owner 得到当前状态。普通点团代入直线轨迹，周期团代入奇偶公式。最后按询问原编号输出。同一时刻的询问不会改变任何状态，次序任意。

不变量是：每个当前状态精确表示所含星球的轨迹，直到它与相邻状态下一次接触。初始相同坐标的合并正确；无接触时左右权重不变，直线与周期轨迹正确；最近的接触必然发生在相邻状态之间，因此事件堆不会漏掉变化；事件闭包先使用全部旧轨迹落位，再按真实坐标合并、重新计算速度，精确复现同时更新。这些性质对事件时刻归纳，得到所有查询的正确性。

排序询问需 O(q log q)，排序初始点团及全部事件维护需 O(n log n)，并查集额外为近似线性的 O((n+q)α(n))。可统一写成时间 O((n+q)log(n+q))，空间 O(n+q)。实现使用 64 位有符号整数保存坐标、时间差、权重和及比较表达式，特别是 W 和 2*L 可以达到约 10^14；不要将负权强制转成无符号数。

本题官方时限为 1 秒，实际提交宜采用 C++ 紧凑数组存储状态、链表和并查集，避免每个事件分配许多小对象。工程中的验证脚本实现了完整堆事件算法，并与独立的逐秒同时更新模拟逐个查询对照；还检查了负权平移、同刻双侧接触、乱序查询、初始重合及 10^9 时刻。它用于验证推导与边界，并未验证 n=10^5 的极限运行时间，也未在线提交。
