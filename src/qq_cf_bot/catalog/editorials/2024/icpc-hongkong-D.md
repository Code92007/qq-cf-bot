# D · Master of Both VI

## 先学什么

先学两状态动态规划、min-plus矩阵乘法、树上LCA与动态线段树合并。建议依次做“单个点的攻击历史”“树上暴力路径历史”“离线集合合并”三个版本，最后再组合。

## 题意

树上每次A x y z给路径x到y的全部点追加一次伤害z。询问D x h时，已知x处护盾初始血量h、现在仍未损毁，问它最多可能承受多少次历史攻击。每次攻击可以减半，但不能连续两次减半；血量≤0即损毁。

因为护盾安装后承受该点全部后续攻击，所以选择的是当前历史的一个后缀。n≤5×10^5、q≤3×10^5，z≤370，h≤10^9。

## 单个点：两状态DP及矩阵

把血量与实际损血同时乘2，普通一击花2z，减半一击花z，避免浮点。状态0/1表示上一击普通/减半。转移矩阵为

```text
M(z) = [ 2z   z  ]
       [ 2z  INF ]
```

矩阵行是旧状态、列是新状态。采用min-plus乘法：(A⊗B)[i][j]=min_k(A[i][k]+B[k][j])。按时间正序相乘就能把整段转移合成一个矩阵。

开头可视为前一次为普通，初始向量(0,INF)，所以整段最小损血为乘积第0行的最小值。护盾仍活着要求严格小于2h，等于时已经损毁。

例如伤害[2,2]，两次不能同时减半，最小实际损血3；h=3时不能承受两次，h=4时可以。

## 每个点的攻击集合怎样离线得到

给每次攻击一个唯一时间编号t，记录伤害z。把t插入x和y两个端点的集合；令l=LCA(x,y)，在parent(l)安排删除t，若l为根则不删除。

从叶到根，先把各孩子集合取并，再加入当前点的端点攻击，最后执行安排在当前点的删除。此时集合恰好是所有攻击路径经过该点的编号。

原因是编号从两个端点分别向上流动，到LCA汇合成同一个编号，在LCA父亲处消失。因此恰在x到y路径出现。这里必须是集合并：同一个编号出现两次要合为一次，不能把伤害算两次。

这和常见的“端点+1、LCA-1、LCA父亲-1”的数值树差分不同。本算法用集合并去重，因此只在LCA父亲删除一次即可。

## 动态线段树保存集合及矩阵

每个树点持有一棵动态线段树，范围为全部事件时间。存在攻击的叶子放M(z)、计数1；不存在的叶子放单位矩阵I、计数0。内部保存左乘积⊗右乘积和计数和。

合并两棵线段树时：一侧为空就复用另一侧；两侧都非空则递归合并；同一个时间叶子只保留一份。删除时将对应叶子恢复单位矩阵。

在树点完成合并和删除后，回答挂在它上面的所有历史询问。线段树可能含未来攻击，所以每次询问只能访问时间小于该询问的前缀。

## 在线段树里找最长可承受后缀

从右往左扫描这个时间前缀，维护已接受的较晚攻击乘积acc和攻击数。

遇到一个完整线段，尝试candidate=该段乘积⊗acc。若其第0行最小值<2h，整段接受；否则向下递归，先右孩子后左孩子。遇到第一个无法接受的实际攻击叶子就停止。

伤害全为正，向左加入更早攻击不会使最小总损血下降，所以这个贪心边界搜索正确。每个成功整段计数使用“攻击叶子数”，而非事件区间长度，因为中间可能有询问事件或不经过本点的攻击。

前缀分解和一次下降合计O(log q)；不需要二分答案再反复做矩阵区间查询。

## 复杂度、内存与核验

LCA用倍增预处理O(n log n)，所有攻击插入、删除与查询共O(q log q)。动态线段树合并总工作也为O(q log q)：每次两侧非空的递归合并都会消耗一个不再单独使用的节点，而总分配节点数为O(q log q)。

空间O(n log n+q log q)。使用节点池、迭代遍历树，避免500000层递归爆栈；min-plus中的INF加法要防溢出。复用孩子线段树后，孩子查询必须已经回答，不能再依赖旧根。

工程实际实现动态线段树合并/删除与后缀搜索，对照暴力展开的每点路径历史，再枚举每个后缀所有不连续减半选择，核验查询结果。尚未在线提交。
