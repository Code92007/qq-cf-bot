# L · Flipping Paths

## 先学什么

先学异或与奇偶不变量，再学两条局部路径RD、DR的区别。下面给出具体坐标构造，不需要把官方图示的“处理对角线”当成黑盒。

## 题意

n×m黑白网格，每次选一条从左上到右下、只向右或向下的路径，翻转沿途全部格子。要求最终全同色，最多400次；n、m≤200。

正式题面的W/B名称与常用英文颜色缩写不同，但这里只需要把两种字符当作0/1，不影响算法。

## 可行性的完整条件

先枚举最终颜色target，令b[i][j]=当前颜色 XOR target，1表示还要翻转。

每条反对角线i+j=d上，一条单调路径恰经过一个格子。因此每次操作都会同时改变所有反对角线的错误格数奇偶。想全部变0，初始各条反对角线的错误奇偶必须相同。

下面构造证明这个条件也充分。如果两种target都不满足，则NO。

## 留一条边界路径到最后

以下坐标为0下标。把最上行i=0和最右列j=m-1留到最后，它们组成路径P=先全R、再全D；P在每条反对角线上恰占一格。

其余需要处理的内部集合为i≥1且j≤m-2，注意它也包括最左列和最下行，不只是几何意义的内部。

按照主对角线d=i-j从大到小处理。固定d，把这些待处理格按i递增列为(i,j)、(i+1,j+1)、...。

## 一条路径如何独立选择整条对角线

对待处理格(i,j)，从它上方(i-1,j)走到右方(i,j+1)，恰有两种两步走法：

```text
DR：经过(i,j)，翻转当前待处理格；
RD：经过(i-1,j+1)，不翻转当前待处理格。
```

所以当前格b=1时选DR，b=0时选RD。连续两个待处理格中，前一段终点恰好等于后一段起点，可以直接拼起来。

路径开头从(0,0)到第一个格上方：第一个格不是在最左列，就是在第二行，所以这段完全在最左列或最上行。路径结尾从最后一个格右方到右下：完全在最下行或最右列。这样得到一条合法完整路径，恰好把本条主对角线的待处理格都修成0。

## 为什么不会改坏之前处理的格

局部另一条路线经过(i-1,j+1)，其主对角线编号是d-2，比当前小，尚未处理。连接点在d-1上，也尚未处理。

开头若在最左列，其行号小于当前格，故主对角线编号更小；若在最上行，则属于最后才处理的边界。结尾最下行部分同样只会走到编号更小的格，最右列部分属于保留边界。

因此没有已处理的非边界格被再次翻转。按d下降完成后，所有错误只可能留在P上。

## 最后一次与操作数

全程每条反对角线奇偶仍保持一致，而P在每条反对角线上只留一个候选格。因此P上的剩余b值全部相同：要么全0，已经完成；要么全1，再翻转一次P即可。

非边界格的d范围是3-m到n-1，共n+m-3条对角线；加上最后一次，总≤n+m-2≤398。若n=1或m=1，只有唯一完整路径，奇偶条件就等价于初始已经全同色，直接零次即可。

## 伪代码与复杂度

```text
for d = n-1 down to 3-m:
    cells = [(i,i-d) : 1≤i<n, 0≤i-d<m-1]
    path = 到第一个格上方的边界段
    for (i,j) in cells:
        path += (b[i][j] ? DR : RD)
    path += 到右下角的边界段
    真实翻转path经过的所有格子，并记录path
如果左上格仍为1：翻转先R后D的边界路径
```

生成与回放总O((n+m)²)，空间O(nm+(n+m)²)计入输出。每条路径包含起点和终点，模拟时别漏；局部拼接点只能翻转一次，不应每段单独翻转重叠端点。

工程对所有不超过3×3的网格，枚举完整路径的异或线性空间核验可行性；另外对500个最大到200×200的随机可行网格回放全部构造，检查目标颜色、路径边界和次数。尚未在线提交。
