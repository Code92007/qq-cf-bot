# D · A Simple String Problem

## 先学什么

先掌握最长公共前缀LCP、最长公共后缀LCS的查询，再学习后缀数组、height数组与RMQ。若暂时不会后缀数组，可以先用逐字符比较实现下面的判定，在小数据上与暴力路径枚举比较，理解算法后再替换查询模块。

## 把向下的一步变成一次字符串切换

两行字符串S、T长度n<=200000。路径只能向右或向下，因此最多从上行切到下行一次。注意向下时，原列的上、下两个字符都会被读到，不能把它误写成同下标直接拼接。

用两个互不相同且不在字母表里的字符，构造U=S+'#'、V='$'+T，长度N=n+1。现在所有跨行路径都可表示为

```text
U[l:j] + V[j:r]，使用半开区间。
```

其中j对应原网格向下后的位置。纯上行或纯下行也可视为切换点在区间外。两个特殊字符各出现一次，所以不可能出现在平方串中；它们负责对齐坐标，不会引入额外答案。

## 固定半长d，把问题变成三种布尔比较

平方串长度2d，设它在上述统一坐标中占[l,l+2d)，切换点为j。对每个p∈[l,l+d)，要比较路径上的位置p和p+d。

定义三个比较数组，坐标范围0<=p<N-d：

```text
A[p] = (U[p]==U[p+d])，两端都在上行；
B[p] = (U[p]==V[p+d])，前半上行、后半下行；
C[p] = (V[p]==V[p+d])，两端都在下行。
```

若切换点在平方串后半，比较顺序是先A再B；若切换点在前半，则先B再C。某一段可以为空，恰好包含纯上行、纯下行情况。

所以问题等价于：是否存在长度至少d的连续坐标区间，可以用“A成立的一段接B成立的一段”，或者“B成立的一段接C成立的一段”覆盖。

## 每隔d放一个锚点，只需四种延伸

任何包含d个连续整数位置的区间都至少包含一个d的倍数。枚举锚点p=0,d,2d,...，数量O(N/d)。以锚点为中心，用LCP/LCS分别求A、B、C成立的最大连续区间[LA,RA)、[LB,RB)、[LC,RC)。例如

```text
LA=p-LCS(U[0:p],U[0:p+d])；
RA=p+LCP(U[p:N],U[p+d:N])。
```

B只需将第二个U换成V，C则两边都换成V。若锚点处比较不成立，右延伸长度为0，不影响下面判定。

对于A接B，锚点要么在A段，要么在B段，因此检查：

```text
(RA-LA) + LCP(U[RA:N],V[RA+d:N]) >= d；
(RB-LB) + LCS(U[0:LB],U[0:LB+d]) >= d。
```

对于B接C，同理检查：

```text
(RB-LB) + LCP(V[RB:N],V[RB+d:N]) >= d；
(RC-LC) + LCS(U[0:LC],V[0:LC+d]) >= d。
```

任意一式成立，就存在长度2d的平方路径。

## 为什么最大化一段不会错过正确切点

以A接B且锚点落在A为例。把A段向两侧扩展到最大区间，只会让可用左端更靠左。若A最大右端已越过原候选右端，它自己就足够长；否则从这个右端到原候选右端都仍属于原来的B段，因此向右查询B一定能覆盖。锚点在B段的情况左右对称，B接C也一样。

反过来，每个成功的式子都明确提供一个连续A接B或B接C区间。截取其中任意d个连续位置，按分界点确定跨行位置j，就得到合法平方串。因此判定既不漏解，也不产生假解。

## 查询实现、例子与复杂度

将U、V及二者反串用不同分隔符拼接，建立后缀数组与height的RMQ。LCP通过后缀排名区间最小值获得；LCS转换为反串LCP。每次查询都要按原子串边界截断长度，空串的LCP/LCS为0，不能越过分隔符。

例如上行abcab、下行acabc，路径可形成abcabc，算法在d=3时找到对应的A接B或B接C区间，输出6。

从d=floor(N/2)递减尝试，第一个成功的d给出最大答案2d；全部失败输出0。所有锚点数量之和为sum O(N/d)=O(N log N)，每个锚点常数次O(1)查询，连同后缀数组与RMQ预处理，总O(n log n)。空间取决于RMQ实现，稀疏表为O(n log n)。

普通双哈希配二分求LCP会再多一个log，并引入碰撞概率；正式规模建议使用确定性的后缀数组查询。本文验证覆盖的是三种比较与锚点延伸归约，尚未验证生产级后缀数组实现的极限性能。
