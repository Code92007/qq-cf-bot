# J · Japanese Bands

## 先学什么

学习路径：多重集计数 → 插板法 → 二进制集合 → SOS DP（子集和）。先在 m<=4 时直接枚举两种颜色的每个数字出现次数，再理解为什么可以只枚举“只在红色出现、只在蓝色出现、两边都有”三种状态。模数是10^9+7，不是常用的998244353。

## 把限制变成两个独立集

设限制中实际出现了 M 种数字，未出现的 U=m-M 种数字完全自由。每个出现过的数字至少要在一边出现。令 R 为只在红卡出现的数字集合，B 为只在蓝卡出现的集合；剩下的 M-|R|-|B| 种两边都有。

必须有 R∩B=空集。对于任意限制(a,b)，a、b不能同时属于 R，也不能同时属于 B；否则无法形成异色卡对。反过来，只要避免这两种情况，该限制就一定能满足。因此 R、B 都必须是限制图上的独立集。自环(a,a)意味着 a 必须两色都有，任何包含它的独占集合都不合法。

## 固定独占集合后用插板法

红卡禁止使用 B 中的 |B| 种数；其余数字中，有 M-|B| 种必须至少出现一次，U 种自由。先给必需数字各分配一张，再把剩余卡片分给 m-|B| 个数字，得到

```text
redWays(B) = C(n1+U-1, m-|B|-1)
blueWays(R)= C(n2+U-1, m-|R|-1)
```

不足以给必需数字各分一张时，组合数自然为0。允许的数字个数为0时，下标为-1，也应返回0，因为题面 n1,n2>=1。这里每色卡片视为多重集，不能再乘排列阶乘。

## 用子集和把3^M压到M·2^M

定义 `f[B]=redWays(B)`，若 B 不是独立集则 f[B]=0。做 SOS DP：

```text
F=f
对 bit=0..M-1：
    对包含bit的mask：F[mask]+=F[mask去掉bit]
```

完成后 F[S] 等于所有 B⊆S 的 f[B] 之和。于是答案是对所有合法 R 累计

```text
blueWays(R) * F[全集 ^ R]
```

补集确保 B 与 R 不相交，f 的合法性确保蓝色独占集合内部没有限制边。每一组多重集唯一确定 R、B，因而没有重复计数。

## 合法掩码与大上标组合数

每个数字用一个位掩码 adj[v] 保存限制邻居，包含自环位。取 mask 的任一置位 v，设 rest=mask去掉v，则 `good[mask]=good[rest] 且 (adj[v]&mask)==0`。每个掩码只需 O(1) 判断。

组合数上标可能接近10^9，下标始终不超过19。使用下降乘积 `N*(N-1)*...*(N-r+1)/r!`，模意义下乘逆阶乘；r<0或N<r时返回0。即使 N 略大于模数，这个小下标公式仍成立，因为 r! 不含模数因子；不要为上标开10^9大小的阶乘数组。

总时间 O(M·2^M+m²+k)，空间 O(2^M+M)。可按集合大小预计算两个颜色的组合数。重复限制边不改变合法性；自环不可漏掉。工程用小规模所有多重集直接检验每条异色限制来对拍。
