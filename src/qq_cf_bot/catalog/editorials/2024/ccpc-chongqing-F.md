# F · Pico Park

## 题意与规模

n 名玩家站成一排，各朝左或朝右，按一个排列依次行动。尚未被击中的玩家开枪，击中朝向上的第一个尚未被击中的玩家；已经被击中的玩家跳过。对每个 k，求最后剩 k 人的排列数，模 998244353。n≤500。

## 先学什么

排列的相对顺序 → 两个有序序列的交错组合数 → 区间划分 DP。先模拟 n≤4 的全部排列，注意“被击中的玩家仍然占据排列中的一个位置，但轮到他时不行动”。漏掉这些位置会少算方案。

## 每个幸存者对应一条攻击链

若 x 击中 y，连边 x→y。每人至多开枪一次、被击中一次，所以每点入度和出度均≤1；边也不可能成环，因为被击中后无法再行动。最终是若干条有向链，每条链的起点是唯一幸存者。

每条链包含的原位置组成一个区间。可以用过程不变量理解：最初每人各成一个区间，每个区间恰有一个存活点。一个尚未行动的存活玩家还没有击中过别人，因此它的链只有自己；它击中最近的存活点，就是把自己这个单点区间与朝向上相邻的链区间合并。各链始终构成不交区间划分。

于是先计算 W[l,r]：区间 [l,r] 的玩家恰好形成一条链、且没有向区间外击中的内部相对顺序数，再做区间划分。

## 一条链必须是 R…RL…L

把沿攻击箭头走到尽头的点称为终点 t，它没有成功击中别人。注意它是第一次成功攻击的目标，并非时间上最后被击中的人。其余人的成功攻击按时间顺序，可以看成从 t 开始，逐步把相邻点接入已形成的区间。

从左侧接入的玩家必须朝右，且顺序必须是 t−1,t−2,…,l；从右侧接入的玩家必须朝左，顺序必须是 t+1,t+2,…,r。因此区间方向只能是若干 R 后接若干 L。

设长度为 m，左侧 R 有 a 个，右侧 L 有 b 个。若 a,b 都正，终点只有两种可能：最后一个 R，或第一个 L。对应 m−1 名成功攻击者的交错数分别是 `C(m−1,a−1)` 与 `C(m−1,a)`。

终点自己的行动不能在所有成功攻击之前，否则它会先击中别人。只要不是第一个，它就已被第一次成功攻击击中，此后排在哪里都无影响。因此终点有 m−1 个插入位置，得到：

```text
a>0,b>0: W[l,r]=(m−1)*C(m,a)。
```

例如 RRLL，m=4,a=2，W=3×6=18。

## 全向一侧与边界的特殊情况

全 R 时，终点只能是最右端 r，其余人的顺序唯一。通常终点不能最先行动，所以 W=m−1。但若 r 恰好是整场最右端 n，它最先开枪也只会打空，于是多一个合法位置，W=m。

全 L 完全对称。汇总为：

```text
区间中出现 L 在 R 左侧：W=0
全 R：W=m−1+[r==n]
全 L：W=m−1+[l==1]
其余 R^a L^b：W=(m−1)*C(m,a)
```

这一公式也包括 m=1：内部单人区间 W=0，只有最左端向左或最右端向右的单人区间 W=1。不能把所有单人区间都当成一种方案，否则会把本应射向邻段的玩家错误地算作独立幸存者。

## 区间划分 DP

设 dp[r][k] 为前 r 人分成 k 条攻击链的排列数，dp[0][0]=1。枚举最后一条链 [l,r]，其长度 m=r−l+1：

```text
dp[r][k] += dp[l−1][k−1] * W[l,r] * C(r,m)。
```

前段已有相对顺序，新区间也有相对顺序，C(r,m) 选择新段成员在合并排列中的位置，即可任意交错。两个区间均不向外产生有效攻击，交错不会改变各自内部结果。反之每个实际排列的最终链区间划分唯一，所以既不漏计也不重复。

预处理组合数、每段 R 数量以及是否出现先 L 后 R，可在 O(n²) 求全部 W。DP 时间 O(n³)，空间 O(n²)。输出 dp[n][1..n]。乘法用 64 位并及时取模。

## 本工程验证

对小 n 枚举全部行动排列，直接模拟存活人数，与全部 k 的区间 DP 结果比较。重点覆盖全同向、LR、RL、内部单人段、RRLL，以及官方三组样例。未提交在线评测，未对 n=500 做性能计时。
