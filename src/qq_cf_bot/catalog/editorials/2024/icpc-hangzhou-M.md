# M · Make It Divisible

## 先学什么

需要 gcd、约数枚举、单调栈与笛卡尔树。先写小规模暴力：对每个子数组求最小值，检查是否整除其它值。再学习“区间最小值的递归树”如何把全部 O(n²) 个区间的条件压缩为 n-1 条父子边。

## 全数组先把候选x压到少量约数

令 mn=min(b)，D=gcd(|b2-b1|,|b3-b2|,...,|bn-b[n-1]|)。如果整个加 x 后的数组满足条件，那么它的最小值 mn+x 必须整除所有元素，也就必须整除全部差分，因此 mn+x 是 D 的约数。

反过来，D 的约数只能保证整个数组好，不能保证每个子数组都好，后面仍需检查。若 D=0，则所有 b 相等，加任意正整数 x 后仍全相等，答案直接是 `k` 和 `k*(k+1)/2`，n=1也在这个分支。

D>0时，用试除枚举 D 的所有正约数 d，取 x=d-mn，只保留1<=x<=k。这样最多只有约数数量 τ(D) 个候选。

## 笛卡尔树为什么适合所有区间

建立以 b 为优先级的最小笛卡尔树：中序遍历是原数组顺序，父亲值不大于孩子值。给所有值加同一个 x 不改变大小关系，所以只需建一次树。重复最小值用固定规则打破平局即可，例如栈弹出条件采用严格大于。

关键判定：加 x 后，每个子数组都好，当且仅当每条笛卡尔树父子边(u,v)都满足 `(b[v]+x) % (b[u]+x) == 0`。

必要性：父亲的整棵笛卡尔子树是原数组中的一个连续区间，父亲是其中最小值。该区间若好，最小值必然能整除包括孩子在内的全部元素。

充分性：对任意子数组，取其最小值所在节点 z。笛卡尔树的区间最小值性质保证，区间内所有节点都是 z 的后代。沿父子边反复使用整除关系，b[z]+x 能整除区间所有值。因此每个子数组都好。

这把官方的“每个递归区间检查 gcd”化成了父子边整除检查，不再需要 RMQ。

## 单调栈建树

从左到右处理位置 i，维护值不降的栈。不断弹出 b[top]>b[i] 的节点，并记住最后弹出的 last；若栈非空，把 i 接为栈顶的右孩子；若 last 存在，把 last 接为 i 的左孩子；然后压入 i。对应更新父亲数组，最终每个非根节点恰有一个父亲。

也可以只记录父亲：弹栈后先令 parent[i]=当前栈顶（若有），再令 parent[last]=i。其它被弹节点的父子关系不变。重复值相等时不弹，它们形成合法的同值链，整除条件自动成立。

## 例子、复杂度与边界

b=[7,79,1,7,1] 的最小值为1，差分 gcd 为6。候选 d=1,2,3,6，对应正 x=1,2,5；逐边检查后都可行，输出数量3、和8。b=[1,2] 时 D=1，但要求 d>mn=1，没有正 x，输出0 0。

建树 O(n)，约数枚举 O(sqrt(D))，逐候选检查 O(n·τ(D))，空间 O(n+τ(D))。D<10^9，约数数量有限；遇到第一条不整除边即可停止当前候选。答案和可达5×10^17，使用64位整数；全相等分支的乘法也必须先提升到64位。输出是“数量与总和”两项，不能只按官方摘要的简写输出总和。
