# C · Giving Directions in Harbin

## 先学什么

学习模4表示方向、简单模拟。最稳妥的构造是保留原路线，只把绝对朝向的改变翻译成左转或右转，不必另找最短路线。

## 按顺时针给四个方向编号

每组n<=10条指令，每次沿N、E、S、W中的一个方向走1到10个路口；相邻方向既不同，也不相反。用N=0、E=1、S=2、W=3表示顺时针次序。

初始朝向直接设为第一条指令的方向，先输出Z和第一条距离。之后从旧方向old变成新方向new，计算delta=(new-old+4)%4。delta=1表示右转R，delta=3表示左转L；转向后输出Z及这一段距离。

题面保证不会出现delta=0或2，所以无需处理连续直走或掉头。总指令数为2n-1，至多19，满足1..20的限制。

## 例子与正确性

先向南走2，再向东走1。南编号2，东编号1，差值模4为3，所以输出初始S、Z 2、L、Z 1。面对南时左侧正是东，不能把平面图上的左右与当前面向的左右混淆。

归纳地，每一段Z开始前，当前朝向都等于对应原指令方向，距离也完全相同，因此经过的位置与终点逐段一致。即使路线最后回到起点，构造也照常有效。

输出严格交替为直走、转向、直走，首条为Z，没有相邻的L/R，也没有连续相同类型指令，符合所有格式约束。每组时间O(n)，空间O(n)用于存输出；也可读完原指令后直接按顺序输出。
