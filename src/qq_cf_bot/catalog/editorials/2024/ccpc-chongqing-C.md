# C · 连方

## 题意与规模

给定长度 n 的首尾两行 a、b，构造 7×n 的 `#/.` 矩阵：所有 # 八方向连通，而每个四方向连通块都必须是实心矩形。n≥2，总长度≤2×10^5；a、b 都至少有一个 #。

## 先学什么

先理解四连通和八连通的区别：两个 # 只在角上接触时，它们八连通、四不连通。这允许我们用“对角接触的矩形”串起整张图。学习顺序是网格连通块 → 矩形包围盒 → 构造题的局部不变量。

## 先处理满行

若某一行全是 #，它所属的矩形横跨全部 n 列。相邻行只要有一个 # 与它竖直相接，就必须整行都是 #，否则该连通块不是实心矩形。

因此，从全 # 的第一行向下延伸，下一行要么全 #，要么全空；但全空行会切断八连通，无法连接有 # 的最后一行。所以第一行全 # 时，整张图都必须全 #。由上下对称性：a、b 恰有一个全 # 时无解；两个都全 # 时输出全 #。

## 用互补行连接任意非满行

以下 a、b 都既有 # 又有 .。

第二行取 a 的逐字符补集：a 是 # 的位置填 .，a 是 . 的位置填 #。这样两行之间没有竖直相邻的 #，每个四连通块只是一个水平连续段，是矩形；当 a 从 # 切换到 . 或反过来时，上下两行的段通过对角相邻接起来。因此前两行的所有 # 八连通。

同理，第六行取 b 的补集，第七行为 b。这给出了两个合法的上下部件。

## 只用第三、四、五行连接它们

在 a 中选一个位置 p，使 a[p] 为 #，且左右至少有一个相邻位置为 .。它一定存在，因为 a 有两种字符，可以取任意一次字符变化中 # 所在的位置。b 中同样选择 q。

第三行仅在 p 填 #，第五行仅在 q 填 #，其余填 .。第三行这个点的正上方为空，但斜上方有 #，因此它与上部件只八连通，不会破坏矩形。第五行与下部件完全对称。

第四行按 p、q 的距离处理，以下位置使用相同的下标起点：

1. p=q：仅在 p 填 #。中间三行形成一个 3×1 矩形。
2. |p−q|=1：仅在 p 填 #。第三、四行组成一个 2×1 矩形，与第五行的点对角相接。
3. |p−q|≥2：只在两者严格之间的位置填 #，即 `min(p,q)+1 ... max(p,q)−1`。这一水平矩形的两个端点分别与第三、五行的点对角相接。

例如 p=2、q=6，中间三行可以是：

```text
.#.....
..###..
.....#.
```

三个矩形只在角上相接，不会四连通为弯曲形状。

## 正确性与实现

上、下两个部件各自八连通，中间的三个部件把它们连成一体，所以全图八连通。上下两行内部的四连通块为水平段；中间是前述的水平或竖直矩形；接口处都只对角相接。因此每个四连通块都是实心矩形。

扫描首尾行、找 p 和 q、输出矩阵都是 O(n)，空间 O(n)。两种字符的分界可能在最左或最右端，判断邻居时注意边界。先将第三至五行全部初始化为 . 再设置少数位置，能够避免上组数据遗留。

## 本工程验证

枚举多个小宽度下所有合法的 a、b。对每个构造结果直接 BFS 检查八连通，并检查每个四连通块的点数是否等于其包围盒面积，另外核对首尾行。无解分支由满行传播证明保证。未提交在线评测。
