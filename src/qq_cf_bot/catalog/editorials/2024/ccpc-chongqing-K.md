# K · 小 C 的神秘图形

## 题意与规模

矩阵 Aₙ 的大小为 3ⁿ×3ⁿ。把它划成 3×3 块，只有中间一行或中间一列的块保留递归图形，四角块全为 0。输入两个长度 n 的三进制坐标串，求对应元素。n≤10^5，坐标可有前导 0。

## 先学什么

三进制位权 → 用最高位确定所属子块 → 递归。可以先画 n=1 的图：

```text
0 1 0
1 1 1
0 1 0
```

不需要真的生成矩阵，也不需要把很长的三进制串转为整数。

## 一位对应一层递归

坐标最高位为 0、1、2，分别表示位于前三分之一、中间三分之一、后三分之一。因此最高位中至少一个为 1，才会落在保留的十字形区域；若两者都不是 1，立即落入全零角块，答案就是 0。

如果这一层合法，对 3ⁿ⁻¹ 取模正好等于删掉最高三进制位。题面的递归变成对余下的两个串重复同一判断。

因此答案为 1，当且仅当每一个位置 i 都满足：

```text
a[i]=='1' 或 b[i]=='1'。
```

例如 a=`102`、b=`011`，三位分别由 a、b、b 提供 1，答案是 1。a=`20`、b=`01` 第一位都不是 1，即使后一位合法，答案仍为 0。

## 正确性与实现

对 n 归纳：n=1 时条件就是上面的十字形；n>1 时最高位判断当前块是否保留，合法后答案等于后 n−1 位构成的小矩阵元素，所以所有位都合法才为 1。

从左到右扫描两个原始字符串，遇到一位都不为 1 就输出 0，否则输出 1。时间 O(n)，除输入字符串外 O(1) 空间。前导 0 表示真实的递归层，不能删掉；只判断是否“至少一位为 1”，不是要求恰好一个为 1。
