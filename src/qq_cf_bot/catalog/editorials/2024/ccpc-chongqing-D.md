# D · 有限小数

## 题意与规模

输入互质的 a、b，1≤a≤b≤10^6。选择非负整数 c 和 1≤d≤10^9，使 a/b+c/d 是整数或有限小数，要求 c 尽量小，并输出一组最优的 c、d。

## 先学什么

最简分数 → 质因数分解 → 同余方程 → 扩展欧几里得求逆元。核心常识：最简分数能写成有限十进制小数，当且仅当分母只含质因数 2、5。因为有限小数的分母能整除某个 10 的幂。

## 最优分母为什么只有很少的候选

把 b 中的全部 2、5 因子去掉，记剩余部分为 w，并令 B=b/w。如果 w=1，原分数已经有限，直接输出 c=0,d=1。

否则最优 c>0。可以假设 c/d 最简：若分子分母有公因数，同时约分会严格减小 c，也不会违反 d 的上界。

考虑任意 p≠2,5。a/b 与 c/d 都最简。如果两个分母中的 p 次数不同，相加后分母中较多的那部分 p 不可能被分子抵消。更具体地，设 b 含 p^u，d 含 p^v，u<v，则 ad+bc 中恰含 p^u，而 bd 含 p^(u+v)，约分后仍含 p^v。反向同理。

因此，对每个 p≠2,5，d 必须与 b 含有完全相同的 p 次数。也就是说，最优解一定满足：

```text
d = w * D，D = 2^x * 5^y，x,y≥0。
```

由 d≤10^9，只需枚举对数平方级别的 (x,y)。这一步将十亿种分母压缩成几百种。

## 固定 d 后，最小 c 是一个余数

代入 b=wB、d=wD，有：

```text
a/b + c/d = (aD+cB)/(wBD)。
```

B、D 只含 2、5，故结果有限当且仅当 `aD+cB≡0 (mod w)`。因为 gcd(B,w)=1，B 有模 w 逆元：

```text
c = (-aD * inverse(B)) mod w。
```

取 `[0,w−1]` 内的标准余数，就是这个分母下最小的非负分子。遍历全部候选 d，保留最小 c 即可；相同 c 时任选一个 d。

例如 a/b=1/6，w=3,B=2。取 D=1 得 c=1,d=3，此时 1/6+1/3=1/2，已经有限。

## 实现框架、复杂度与边界

```text
剥去 b 的 2、5 因子，得到 w
若 w==1: 输出 0 1
否则:
    inv = B 在模 w 下的逆元
    枚举 pow2=1,2,4,...，且 pow2≤10^9/w
        枚举 D=pow2,5*pow2,25*pow2,...，且 D≤10^9/w
            c = ((-a*D)%w * inv)%w，统一调整到非负
            用 (c,w*D) 更新最优答案
```

逆元用扩展欧几里得，不能用费马小定理，因为 w 不保证为质数。可先把 aD 对 w 取模再乘逆元，减少中间值；所有乘法用 64 位。循环乘 2、5 前比较上界除以相应因子，可避免溢出。

每组时间 O(log b+log²10^9)，空间 O(1)。最优分数约分论证仅用于证明候选范围，不要求输出时强制再次约分。

## 本工程验证

将分母上界缩小后，枚举全部允许的 d、候选 c，用最简分母是否只含 2、5 直接判断有限性，与枚举 2、5 次幂的方法对拍。覆盖原分数已经有限、复合 w 和有多个最优分母的情况。未提交在线评测。
