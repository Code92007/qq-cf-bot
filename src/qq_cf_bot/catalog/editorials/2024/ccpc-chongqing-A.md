# A · 乘积，欧拉函数，求和

## 题意与规模

有 n 个正整数，求所有下标子集的乘积的欧拉函数之和，模 998244353。空集的乘积为 1，φ(1)=1，因此空集也贡献 1。n≤2000，aᵢ≤3000；即使两个数相同，选择它们的下标仍然是不同方案。

## 先学什么

欧拉函数的质因数公式 → 模逆元 → 状态压缩背包 → 按互不相交的影响范围分组。先会求单个 φ(12)=12×(1−1/2)×(1−1/3)，再理解每个质数的修正因子只乘一次。

## 把乘积和“是否出现质数”分开

公式为 `φ(x)=x*∏_{p|x}(p−1)/p`。对于一个子集，乘积本身可以在选入 aᵢ 时乘 aᵢ；困难只是要记住哪些质数出现过。同一质数无论出现多少次，只乘一次 `(p−1)/p`。

若只有 k 个质数，设 dp[S] 为已经处理的数中，质因数集合恰为 S 的所有选法的乘积之和。初始 dp[0]=1。一个值 x 的质因数集合为 T，转移为：不选 x，保留 dp[S]；选 x，向 `S|T` 加上 `dp[S]*x`。最后对每个 S 乘对应的欧拉修正因子。

3000 以下有数百个质数，不能全部压进状态。关键是：一个不超过 V 的数，至多含一个大于 √V 的质因数，否则两个这样的质数相乘已经超过 V。

## 小质数进状态，大质数分组

把不超过 53 的 16 个质数作为状态位。每个 aᵢ 除去这些小质数后，剩余值要么为 1，要么是一个大质数 p。按这个 p 分组。

不同大质数的组包含互不相交的输入下标。因此处理 p 这一组时，只需知道“这一组有没有选数”，无需把 p 永久放入状态。

设处理本组前的数组为 base，另开 some，初始全部为 0，表示本组已经至少选一个数。依次处理本组的 x，其小质数集合为 T：

```text
next = some                         // 本次不选 x
对所有 S:
    next[S|T] += some[S] * x        // 本组之前已选过
    next[S|T] += base[S] * x        // x 是本组第一个选中的数
some = next
```

注意 base 在整组过程中不变，它表示本组至今一个都没选；只有“不选前面的全部数，再首次选当前 x”这一种情况。

组处理完后，令 `dp[S]=base[S]+some[S]*(p−1)/p`。空选不乘修正因子，非空选恰好乘一次。p=1 的组没有大质数，直接做普通的选/不选背包即可。

全部组结束后，答案为 `Σ dp[S]*∏_{小质数p属于S}(p−1)/p`。

## 小例子与正确性

例如 59 与 118 都属于大质数 59 的组。选两者的乘积为 6962，但只应乘一次 58/59；118 另带的小质数 2 由状态位记录，最后再乘 1/2。不能在选入每个数时都直接乘 φ(aᵢ)，因为欧拉函数对不互质的数并不满足 φ(xy)=φ(x)φ(y)。

每种下标子集在每组内唯一对应空选或非空选，其乘积被背包精确累计；每个大质数在对应组结尾修正一次，每个小质数在最终状态修正一次。因此每个子集贡献恰好为其乘积的欧拉函数。

## 复杂度与实现细节

设 k=16，时间 O(n·2^k)，额外空间 O(2^k)。所有除法使用模逆元，因为这些质数均小于模数。需要使用旧数组生成新数组，不能在原数组中随意顺序更新，以免同一个数重复选择。x=1 的状态集合为空，但选与不选仍是两个不同方案，必须正确加倍。初始 dp[0]=1 已包含空集。
