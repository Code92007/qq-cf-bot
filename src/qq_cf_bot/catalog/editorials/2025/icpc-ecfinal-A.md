# A · Outstanding Outlines

## 先学什么

先学向量点积、二维叉积和分数运算，再学“用两个不平行向量作为坐标轴”。建议先手算：在 A=(0,0)、B=(2,0)、C=(1,1) 时，为什么点 (5/2,1/2) 在一个平移后的斜边上，而点 (2,1/3) 不在？本题不需要计算角度，也不应该使用浮点误差判断整数倍。

## 题目到底允许什么

固定一个非退化三角形 ABC；AB 所在直线和过 C 的平行线组成无限长走廊。用全等三角形铺满走廊，每块都必须同时接触两条边界，而且 ABC 这一块不能改变位置。给定有理坐标 D，问能否让 D 恰好在某块砖的边界上。正式题面 T≤1000，整数顶点坐标绝对值≤100，D 的分子分母绝对值在 10^7 以内。

## 先把无限种铺法压缩成有限种边

官方讲义证明：合法铺法中的每个三角形都有两个顶点落在一条边界、第三个顶点落在另一条边界。可以这样理解这个限制：若内部出现未贯穿走廊的折线，两侧砖边围成的局部区域就会被封住，里面的某块砖无法同时碰到上下边界。因此不能在走廊中间随意拼一个新的小顶点。

从固定的 ABC 向两侧延伸，通常只能不断用相邻三角形绕公共边中点旋转 180 度。产生的内部边，恰好是 AC 与 BC 沿向量 AB 平移整数次所得的线段。特殊情况是底边端点处为直角：还可以沿垂直于走廊的直角边做镜像，产生另一种斜向线段。

## 换坐标以后不需要枚举平移次数

记 X=B-A，Y=C-A。由于三角形非退化，这两个向量线性无关，每个点 D 都唯一写成

```text
D-A = u*X + v*Y
v = cross(X,D-A) / cross(X,Y)
u = cross(D-A,Y) / cross(X,Y)
```

在这个坐标系里，A=(0,0)、B=(1,0)、C=(0,1)。因此：

- v<0 或 v>1：点不在走廊内，无解。
- v=0 或 v=1：点在边界线上，有解。
- 0<v<1：AC 的平移线段满足 u 为整数；BC 的平移线段满足 u+v 为整数。

例如 u=2、v=1/3 位于 AC 向右平移两个周期的边上；u=2/3、v=1/3 位于原来的 BC 上。

## 为什么直角要单独处理

先用点积检查 A 或 B 处是否为直角；若 A 为直角，交换 A、B，重新计算上述坐标，保证直角位于 B。令 Q=A+C-B，则 Q 在新坐标中为 (-1,1)，线段 BQ 的方程为 u+2v=1。

官方几何结论给出的额外合法边是 BQ 沿 AB 平移非零整数次。因此额外判断为：u+2v 是整数，并且 u+2v≠1。排除原 BQ 的原因是它穿过已经固定的 ABC 内部；不能为了铺另一块砖破坏固定砖。其他两类边仍应先判断，因为某个点即使在被排除直线上，也可能已经属于合法边界。

## 精确计算与伪代码

D=(dx1/dx2,dy1/dy2)。把叉积乘上公共分母 dx2*dy2，得到整数 U、V、W，使 u=U/W、v=V/W；若 W<0，三者同时取反。

```text
若 A 处是直角：交换 A、B
计算 U,V,W，保证 W>0
若 V<0 或 V>W：No
否则若 V=0 或 V=W：Yes
否则若 U%W=0 或 (U+V)%W=0：Yes
否则若 B 处是直角且 (U+2V)%W=0 且 U+2V!=W：Yes
否则：No
```

负数取模的结果可能为负，但判断是否为 0 没有问题。分母乘积和叉积必须放进 C++ `__int128`；即使输入坐标不大，中间乘积也可能超过 64 位范围。单组 O(1) 时间、O(1) 空间。

## 正确性与校验范围

上述几何结构列出了全部可能内部边，坐标变换又把每类线段的成员条件精确改写成整除与范围判断，所以判断既不会漏掉合法边，也不会接受固定三角形内部的禁止镜像边。工程校验使用有理数坐标，将整除公式与逐条枚举平移线段的叉积判定对拍；这验证实现，不替代官方铺砖结构证明。
