# K · Cyclic Shift

## 先学什么

先学字典序、单调栈求右侧第一个更大值、相同连续值的游程压缩。本题官方用倍增哈希比较路径；下面利用值严格增加这一结构，用确定性的分层排名实现同一比较，不需要哈希概率。

## 先核对题目方向

正式题面要求输出所有循环移位中，字典序最小的前缀最大值序列。官方讲义第7页英文摘要写了 largest，与正式题面和样例相反；本文以正式题面的 smallest 为准。n≤5×10^5，总 n 同界。

## 前缀最大值可以压成一条链

对位置 i，找环形向右第一个满足 a[j]>a[i] 的位置 j，距离 d=j-i（使用展开后的下标）。从 i 开始的前缀最大值先连续 d 次等于 a[i]，然后沿 j 继续。

例如循环数组 [1,2,1,3,1] 从末尾开始得到 [1,1,2,1,3]，前缀最大值为 [1,1,2,2,3]，压缩链为 (1,2)→(2,2)→(3,无限)。一旦到全局最大值，此后一直不变。

将数组复制成两倍，用单调栈从右往左求第一个严格更大元素。弹栈条件是 ≤，不是 <。若不存在一圈内的严格更大值，这个点就是全局最大值，作为链终点。

## 压缩链的字典序规则

比较两个起点的链：

1. 当前值不同，较小值对应更小的原序列。
2. 当前值相同、持续长度不同，长度较长的更小。因为另一条链先升到严格更大的值，而较长的还停在当前值。
3. 当前值和长度都相同，跳到下一段继续比较。

由于链的值严格递增，不可能循环。全局最大值节点代表同一条无限常数序列，不必区分它们距离下一次出现最大值有多远。

## 不用哈希的排名法

给每个位置一个 rank，数值越小表示整条无限压缩链字典序越小。按 a[i] 从大到小分组处理。

- 最大值组的节点全部取相同 rank。
- 对其他同值组，每个节点的比较键是 (-distance[i], rank[next[i]])。next 的值更大，其 rank 已算好。
- 按键排序，相同键分配相同 rank；键较小的分配较小 rank。
- 当前值比所有已处理值更小，所以本组所有 rank 都必须小于此前全部 rank。

一个方便实现是维护递减编号 counter：同值组将键从大到小排序，每遇到新键就 `--counter` 并分配给它。这样最小键最后获得最小编号，不需要移动已有排名。

处理完后选择 rank 最小的起点，真实遍历恰好 n 个元素，维护最大值并输出。

## 为什么比较无限序列不会改变答案

每个循环起点在前 n 个位置内都能遇到全局最大值，之后其前缀最大值永久相同。因此两个无限前缀最大值序列如果存在差异，第一次差异必在前 n 项内；否则前 n 项已经完全相等。使用无限常数终点只是省掉最后一段长度的处理，比较结果不变。

## 复杂度与实现细节

单调栈 O(n)，按值分组以及组内排序合计 O(n log n)，空间 O(n)。也可利用 a[i]≤n 做桶分组。栈得到的 next 可能≥n，取 `%n` 读取父节点 rank，但距离必须使用展开下标 next-i，不能取模后直接相减。

所有值相等时，全部 rank 相同，任意起点均正确。n=1 也自然处理。工程穷举长度1到8的全部三值数组，枚举每个循环移位直接生成前缀最大值，与分层排名结果比较。尚未在线提交。
