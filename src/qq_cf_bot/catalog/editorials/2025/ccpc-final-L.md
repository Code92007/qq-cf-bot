# L · Spirited Away（神隐）

## 题意与规模

对每个非空连续区间，考虑其中任意多个数异或得到的所有结果组成的集合。问这些集合有多少种。数是 32 位无符号整数，n≤10^5；选零个数的结果 0 也在集合中。

例如 `[1,2,3]` 的区间会产生 `{0,1}`、`{0,2}`、`{0,3}` 和 `{0,1,2,3}`，答案 4。`[1,2]` 与 `[1,3]` 虽然元素不同，但都张成最后这个集合；不能用区间元素的普通哈希来判重。

## 先学什么

建议按二进制异或 → 线性无关 → 异或线性基 → 高斯消元的顺序学习。先能手算为什么 3 可以由 1 xor 2 得到，加入 3 不会增加维数。随后区分普通线性基和规范线性基：前者只保证能表示同一集合，后者保证同一个集合有唯一的表示。

## 为什么只有 O(32n) 个候选

固定右端点 r，让左端点从 r 向左移动。得到的线性空间只会扩大。如果加入一个数没有增加维数，空间不变；如果发生变化，维数至少增加一。维数最多 32，所以每个右端点最多出现 33 个空间，其中第零维空间只可能来自全零区间。

困难变成：如何找到空间发生变化的左端点，而不逐个扫描全部左端点？

## 用“尽量靠右”的线性基压缩所有后缀

维护按最高位消元的基 `basis[bit]`，再给每个基向量附上位置 `pos[bit]`。把 a[r] 连同位置 r 插入：

```text
x=a[r], p=r
for bit=31..0:
    if x 的 bit 位为 0: continue
    if basis[bit] == 0:
        basis[bit]=x, pos[bit]=p
        break
    if pos[bit] < p:
        swap(x,basis[bit])
        swap(p,pos[bit])
    x ^= basis[bit]
```

交换保证高位基向量尽量使用较新的位置。它有一个标准不变量：任意阈值 l，所有 `pos>=l` 的基向量恰好张成原数组 `[l,r]` 的空间。插入时，如果两个向量最高位相同，较新的留在这个主元，较旧的用它消元；消元结果仍由“不早于较旧位置”的原数表示，所以不会破坏任何后缀阈值。

将不为空的基向量按 pos 从大到小排序。依次加入它们，每增加一个向量，就得到一种新的后缀空间。只需至多 32 次加入。如果 `a[r]==0`，还要加入零空间；否则当前右端点不存在非空的全零后缀，不能无条件把零空间计入。

排序 32 个元素是小常数，也可以按位置维护这个短列表。

## 普通线性基为什么还不能直接判重

同一个二维空间，普通基可能是 `[3,1]`，也可能是 `[2,1]`。因此每得到一个候选空间，要将基变成行最简形：每个主元所在位只在它自己的向量中为 1，其余向量在该位全部为 0。

向规范基加入 x 时：

1. 从高位向低位，用已有主元消掉 x 中对应的 1。
2. 若 x=0，空间不变。
3. 否则设新主元为 k；继续用更低位的已有主元消掉 x 中所有已有主元位。
4. 对每个主元高于 k 的旧向量，若其第 k 位为 1，就异或 x 消掉它。
5. 将 x 放在第 k 行。

最终所有主元列都是单位列，且没有主元的行记 0。同一个空间的行最简形唯一，这才可以作为集合的身份。

## 怎样使判重保持 O(32²n)

每个右端点有 O(32) 次加入，每次规范化修改 O(32) 行。如果每次再重新扫描 32 行计算标识，仍然是 O(32²n)。可以给 `(行号,行值)` 使用两个独立的 64 位混合哈希，整个基的标识为各行哈希的异或和；行改变时先移除旧贡献，再加入新贡献。

把得到的双 64 位标识放入哈希集合，大小就是答案。这一步具有极小但非零的碰撞概率，不能称作完全确定性。希望严格无碰撞时，应保存并比较完整的 32 行规范基；时间量级不变，但最坏情况下会使用 O(32²n) 个整数的内存。工程验证使用完整元组作为键，避免把哈希碰撞混入算法正确性检查。

候选数量 O(32n)，基更新时间 O(32²n)；双哈希版本额外空间 O(32n)。数值运算使用 `uint32_t`，构造位掩码使用 `uint32_t(1)<<bit`，不要让最高位左移落到有符号整数的未定义行为。

## 小例子与容易误解的地方

右端点为 `[1,2,3]` 的最后一个 3 时，按右端位置保留的有效向量对应后缀 `{3}` 和 `{2,3}`；前缀的 1 已经由它们异或得到。于是只产生一维空间 `{0,3}` 和二维空间 `{0,1,2,3}`，不会因为左端点再移动到 1 而重复计数。

整个数组都是 0 时，答案是 1。空基是零空间，而非“没有任何结果”的空集合。位置标签代表后缀可用性，不保证当前基向量等于原数组该位置的值，消元后的组合向量同样有效。

## 本工程验证

独立枚举小数组的所有区间以及每个区间全部子集异或结果，将真实集合数量与带位置线性基、规范消元得到的数量比较。验证还检查各阈值对应的完整空间相等；没有提交在线评测，未验证极限规模双哈希的耗时。
