# I · Redundancy Refrain

## 先学什么

先学二分答案、堆，以及区间覆盖的交换论证。这里最关键的是把“两个子数组有相同多重集合”改写成同一数值的最远出现距离。可以先穷举一个短数组，验证这两个量相等，再看填0。

## 题意

长度 n 的数组含 0..k，0 是待填位置。填成 1..k，使两个不同起点、元素多重集合相同的子数组的最大长度尽量小，并输出构造。n≤2×10^5，总 n 同样不超过2×10^5。

## 第一步：消掉子数组比较

记 M 为同一数值最左、最右出现位置的最大距离。若 b[l]=b[r]，区间 [l,r-1] 和 [l+1,r] 只交换了两个相等的端点，所以长度 r-l 的 anagram 一定存在；最长长度至少 M。

反过来，若起点 x<y 的两个长度 L 区间有相同多重集合：若它们不重叠，第一个位置的值必在右区间出现，距离至少 L；若重叠，消去公共部分后，[x,y-1] 与 [x+L,y+L-1] 多重集合相同，b[x] 必在后者出现，距离仍至少 L。所以 M≥L。两边结合，目标恰好等于 M。

## 二分 m 后，每个数字对应一个可以滑动的区间

所有值为 c 的位置必须落在某个跨度为 m 的区间 [s,s+m]，共 m+1 个整数位置。

若 c 的固定出现位置最左为 l、最右为 r，则必须有

```text
r-m <= s <= l
```

若 r-l>m，立即不可行。没有固定出现的数字可取 s∈[1-m,n]，允许区间伸到数组边界之外。

现在只需为每种数字选择一个合法区间，使所有位置被至少一个区间覆盖。若覆盖存在，将每个0填成任意一个覆盖它的数字，固定数字保持原样；每种数字的所有出现位置仍位于自身区间，所以跨度不超过 m。反向也显然成立。

## 覆盖贪心的完整规则

令数字 c 的允许起点区间为 [lo[c],hi[c]]。按 lo 排序，并用小根堆维护 hi。x 是当前第一个未覆盖的位置。

```text
x=1
while x<=n:
    把所有 lo<=x 且尚未入堆的数字加入堆
    删除所有 hi+m<x 的数字：它们再也覆盖不到 x
    若堆空：不可行
    取 hi 最小的数字 c
    s=min(x,hi[c])
    end=s+m
    用 c 填写 [x,min(end,n)] 中的0
    x=end+1
```

每个数字最多被选一次。未被选中的数字仍可给它一个任意合法区间，只是无需用它覆盖新的0。不要覆盖固定非零位置。

## 为什么选最早到期的区间

所有覆盖区间长度相同。假设某个可行方案先用别的数字 d 覆盖 x，而 c 也已可用且 hi[c]≤hi[d]。将 c 尽量向右放到 min(x,hi[c])；若原方案稍后还使用 c，可以把 d 放到原来 c 的位置或更右。因为 d 的最晚起点不小于 c，且它原先已能覆盖 x，它不会因向右推而违反最早起点。这样交换不会减少覆盖到的最右位置，也不会造成 x 之前的空缺。

所以存在遵循当前选择的可行方案。反复交换得到贪心；堆空时，所有未使用区间都不能覆盖 x，确实无解。

## 一个例子

a=[1,0,0,2,0]，k=2。试 m=2 时，数字1的起点范围[-1,1]，数字2为[2,4]。先在 x=1 选数字1，把区间放成[1,3]；再在 x=4 选数字2，放成[4,6]，得到 [1,1,1,2,2]，跨度最大2。

m=1 时两种数字最多各覆盖2个位置，无法覆盖5个位置，因此最优值为2。

## 复杂度与边界

可行性随 m 单调：扩大跨度只放宽约束。二分 [0,n-1]，每次排序和堆操作 O(n log n)，总 O(n log²n)，空间 O(n)。二分阶段只需判断，不必反复写构造；最后用最优 m 再跑一遍。每个0只在最终构造被写一次。

m 是下标距离，区间有 m+1 个位置，不能混淆。k=1 时答案必为 n-1。工程穷举短数组及所有填法，检查最优值、保留固定位置及实际构造跨度；尚未在线提交。
