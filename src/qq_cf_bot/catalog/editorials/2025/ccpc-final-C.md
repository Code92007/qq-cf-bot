# C · Four Kubic Theorem 2（四太祖先父母定理 2）

## 题意与规模

p 为质数，给出四个非零模 p 系数 a[i] 和四个正代价 b[i]。求非负整数 x[i]，满足 `sum(a[i]*x[i])≡m (mod p)`，并最小化 `sum(b[i]*x[i])`。p≤1.01×10^9，所有测试的 ceil(sqrt(p)) 之和≤2^17。

## 先学什么

需要模逆元、抽屉原理、折半/有界枚举和基本复杂度估算。先想清楚：确定前三个 x 后，第四个在模 p 下唯一；由于它的代价为正，只需取最小非负代表。真正难点是如何证明前三个数不必枚举到 p。

## 核心引理：有一个最优解满足乘积界

存在最优解 X，使

```text
(X[1]+1)(X[2]+1)(X[3]+1)(X[4]+1) <= p。
```

证明：在所有最优解中取字典序最小的 X。考虑盒子内所有整数向量 Y，满足 `0<=Y[i]<=X[i]`。若盒子大小大于 p，按 `sum(a[i]*Y[i]) mod p` 分组，必有两个不同向量 U、V 落在同组。

令 Δ=U−V，则 `sum(a[i]*Δ[i])≡0`，且 X+Δ、X−Δ 都非负。若 `sum(b[i]*Δ[i])` 非零，其中一个解比 X 便宜；若为零，两者都最优，而其中一个字典序小于 X。两种情况都矛盾。

这是一个真实的最优性约束，不是根据随机数据猜测变量很小。

## 枚举变量的大小顺序

四个变量有 24 种大小顺序，依次尝试。对当前顺序，不妨令

```text
x1 <= x2 <= x3 <= x4，ui=xi+1。
```

则 `u1*u2*u3*u4<=p` 给出：

```text
u1^4 <= p
u1*u2^3 <= p
u1*u2*u3^2 <= p。
```

所以依次枚举

```text
u1 = 1 .. floor(p^(1/4))
u2 = u1 .. floor((p/u1)^(1/3))
u3 = u2 .. floor(sqrt(p/(u1*u2)))。
```

算出前三个 x 后，第四个由同余式直接得到：

```text
x4 = ((m-a1*x1-a2*x2-a3*x3) * inverse(a4)) mod p。
```

把结果规范到 `[0,p−1]`，检查 `x4>=x3` 及完整乘积界，然后更新最小代价。若某个可行第四变量比这个最小代表还大，它只会更贵；因此不需要再加 p 枚举。

每个最优解至少有一个大小顺序，且存在满足乘积界的最优解，所以不会漏掉答案。相等变量会被多个顺序重复枚举，只影响常数，不影响正确性。

## 为什么是 O(p^(3/4)) 级别

忽略下界只会多算。固定 u1、u2 后，u3 的数量至多约 `sqrt(p/(u1*u2))`。先对 u2 求和，再对 u1 求和：

```text
sqrt(p) * sum_u1 u1^(-1/2) * sum_u2 u2^(-1/2)
= O(p^(2/3) * sum_{u1<=p^(1/4)} u1^(-2/3))
= O(p^(3/4))。
```

24 种顺序是固定常数。官方讲义还给出了 O(sqrt(p) log p) 的折半优化；这里采用其第二种完整枚举做法，证明和实现更直接。其通过依赖紧凑的 C++ 常数实现，不适合用 Python 跑极限数据。

## 实现建议

每个 a 的逆元预处理一次，不要在最内层快速幂。枚举 u3 时，剩余同余可以按固定步长递推，减少乘法和取模。整数根用浮点初值后以整数乘法校正，或者用精确整数开方，防止边界漏枚举。

先把 m=0 特判成 0。答案上界可用“只使用一种变量”的四个方案初始化，之后若当前前三项代价已经超过答案，可以剪枝，但剪枝不是正确性的必要条件。乘积、代价都用 64 位，计算模乘可使用 `__int128`，避免中间表达式产生溢出或负模问题。

## 小例子与验证

若 p=7、a=`[1,2,3,4]`、b 全为 1、m=6，可选 x3=2，代价 2；也可以 x2=x4=1，同样代价 2。算法会在对应大小顺序中找到这些解。

本工程在小质数上，把每个模 p 余数当成图节点，四种操作分别增加 a[i]、付出 b[i]，用 Dijkstra 求真正最小费用；再与乘积界枚举比较。未验证最大 p 的运行常数，也没有提交在线评测。
