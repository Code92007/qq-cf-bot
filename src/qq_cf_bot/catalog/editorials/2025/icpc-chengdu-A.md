# A · A Lot of Paintings

## 先学什么

先理解四舍五入对应的半开区间，再练习把有理数整体乘一个公分母变成整数。不需要浮点计算。一个关键练习是：哪些真实百分比会被记成 25？答案为 `[24.5,25.5)`，左端能取、右端不能取。

## 题目与限制

输入 n 个整数百分数 d[i]，每项在 0 到 100，n 的总和不超过 200000。要构造非负整数 b[i]，总和为正，每项不超过 10^9，使 `100*b[i]/sum(b)` 四舍五入成 d[i]。正式题名是 A Lot of Paintings，讲义中 A 的标题不同，但对应的是同一道比例恢复题。

## 从误差范围得到判定

记 S=sum(d)，c 为非零项个数。真实百分比总和必须等于 100。每个正数最多向下修正 0.5；零不能变成负数。因此最小可能总和是 `S-c/2`，必须不超过 100，即 `2*S-c<=200`。

反方向，每项只能增加严格小于 0.5。故需要 `2*S+n>200`。当输入含 100 时，其真实百分比不能超过 100，但不会破坏下面的构造：S=100 直接取原值；S>100 只做减法。于是判定可以统一成

```text
2*S-c <= 200 且 2*S+n > 200。
```

注意两个比较符不同，来自“恰好 0.5 向上舍入”。例如 `[33,33,33]` 有解，而 `[0,0]` 无解。

## 将判定变成具体构造

若 S>100，要减去 S-100。选择恰好 `2*(S-100)` 个非零位置，各减 0.5，再把所有数乘 2。也就是先令 b[i]=2*d[i]，再把选中的项减 1。第一个判定保证非零位置足够。此时 sum(b)=200，每项比例恰为 d[i] 或 d[i]-0.5，均会舍入为 d[i]。

若 S<=100，把差额均分给 n 项，得到真实百分比 `d[i]+(100-S)/n`。第二个判定保证增加量严格小于 0.5。无需存小数，直接输出

```text
b[i] = n*d[i] + (100-S)。
```

总和是 100*n，所以它的真实百分比正好是上述值。S=100 时也适用。每项最多约 2*10^7，满足输出上界。

## 例子、证明与复杂度

`[25,25,25,26,0]` 的 S=101，选择前两个正数，输出 `[49,49,50,52,0]`。总和 200，百分比分别为 24.5、24.5、25、26、0，舍入后正好恢复输入。

无解判定由比例范围给出必要条件；两种构造证明满足条件时一定有解，合起来就是充要条件。每组 O(n) 时间、O(n) 输出空间。S 和计算式用 64 位整数；不要用浮点 round，因为语言的舍入规则可能是银行家舍入。
