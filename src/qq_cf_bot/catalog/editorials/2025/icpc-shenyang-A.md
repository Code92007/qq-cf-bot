# A · Square Kingdom

## 先学什么

先学二分答案、整除向下取整和有理数约分。这里 n 可达10^12，不能生成所有差值；关键练习是把“第k小”改成“有多少项不超过某个值”，再证明只需枚举 O(√k) 种下标差。

## 题意

h[i]=(i+b/a)²，求所有 i<j 的 h[j]-h[i] 中第k小，输出最简分数。n、k≤10^12，a≤10^6，b≤10^12。

## 消掉平方与分数

令 d=j-i≥1，则

```text
h[j]-h[i] = d*(2i+d+2b/a)
a*(h[j]-h[i]) = 2adi + ad² + 2bd
```

右式是整数，所以二分整数 R，判断原差值≤R/a 的对数是否至少k。固定 d 后，可选 i 满足

```text
1 <= i <= min(n-d, floor((R-ad²-2bd)/(2ad)))
```

该上界小于1时贡献0，否则就是上界本身。相同差值来自不同数对时要分别计数，不能去重。

## 为什么不需要枚举到 n

取最小 q≤n，使 q(q-1)/2≥k。前 q 个居民产生的所有差值均≤h[q]-h[1]，所以第k小一定不超过它。对任意 d≥q，由于 h 单调且相邻增量递增，最小差值也有 h[1+d]-h[1]>h[q]-h[1]，不可能影响二分范围内的计数。

因此只枚举 d=1..q-1，q=O(√k)。可用整数平方根估计 q，再用 q(q-1)/2 的精确比较修正，避免浮点边界。

二分上界的整数形式为 a*(q²-1)+2b*(q-1)。计数累积到k即可提前结束。还可以发现最小 i=1 对应的值随d递增，若 R<ad²+2bd+2ad，后续d全无贡献，可以直接停止。

## 例子与实现

n=3,a=3,b=1，乘a后的三个差值是11、17、28，第2小为17，所以输出17/3。不是把平方后的分母直接写成a²；平方差中 b²/a² 已抵消，最终分母至多为a。

二分得到 R 后，g=gcd(R,a)，输出 R/g 与 a/g。所有乘法、上界和二分中点使用 `__int128` 计算；不要先用64位相乘再强转。中点写 lo+(hi-lo)/2。

时间 O(√k log R)，空间 O(1)。工程枚举小 n 全部数对，以精确分数排序逐个核对所有k。尚未在线提交。
