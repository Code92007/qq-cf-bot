# L · 区域赛冠军

## 先学什么

按这个顺序学习：两条曲线的交点怎样把一条曲线切成小段 → 新增一段为什么多出一个区域 → 叉积判断线段相交 → 有理数坐标与整数几何。欧拉公式可以帮助统一计数，但不用先学完整的计算几何模板库。先自己画出“两圆相交得 4 个区域”和“三条不平行、不共点的直线得 7 个区域”，再读构造部分。

本题不只是输出最大值，还要给出整数坐标。每种图形至多 100 个，坐标绝对值不超过 1000，圆半径在 1 到 1000 之间，且至少有一个图形。下面给出可以直接实现的确定性坐标，并解释怎样验证它们没有退化。

## 第一步：先算每一对最多相交几次

圆与圆至多交两次；直线与圆至多交两次。直线穿过凸三角形时只会进入、离开各一次，所以直线与三角形至多交两次。圆与三角形的三条边分别至多相交两次，总共至多六次。两个三角形也至多相交六次：把第一个三角形的每条边看成一条直线，它与第二个凸三角形至多相交两次。

| 两种图形 | 最大交点数 |
| --- | --- |
| 圆、圆 | 2 |
| 三角形、三角形 | 6 |
| 直线、直线 | 1 |
| 圆、三角形 | 6 |
| 圆、直线 | 2 |
| 三角形、直线 | 2 |

于是所有不同图形之间的交点数上界为

```text
P = n*(n-1) + 3*m*(m-1) + k*(k-1)/2
    + 6*n*m + 2*n*k + 2*m*k
```

这里的交点必须都是普通的横穿：相切、三条边界共点、边界重合，都会使实际新增区域数减少。仅仅逐对达到表中的交点数还不够。

## 第二步：为什么答案是 P 加一个常数

先考虑有直线的情况。第一条直线把平面分成两个区域。第 j 条直线被之前的 j-1 条直线切成 j 段，每段各切开一个旧区域，所以 k 条一般位置的直线总共得到 `1+k+k*(k-1)/2` 个区域。

随后画圆或三角形。一条闭合边界若与已有边界有 t 个互不相同的横穿交点，就被切成 t 段；每段切开一个区域，新增 t 个区域。因此当 k>0 时，答案为 `P+k+1`。

如果 k=0，先画任意一个圆或三角形，区域数从 1 变成 2；之后每条闭合边界新增的区域数仍等于交点数。因此答案为 `P+2`。

统一写成：

```text
answer = P + k - (k > 0 ? 1 : 0) + 2
```

为什么这是上界，而不只是某种画法的计数？每新增一条闭合边界，它有交点时至多增加交点数个区域；没有交点时只增加 1 个。已有图形非空时，该图形与它们的逐对交点上界至少为 2，因此不相交不会带来更优结果。直线则至多增加“交点数+1”个区域。逐个加入图形即可得到上面的统一上界。

例子：n=m=1、k=2 时，`P=1+6+4+4=15`，答案为 18，与题面样例一致。只画一个圆得到 2，只画一条直线也得到 2。

## 第三步：把“微小扰动”变成具体整数坐标

官方的思路是先画一个大圆、大三角形和一条直线，使它们充分相交，再小幅移动产生多份。这里使用同一组基准点：

```text
B=(-900,-1000)   C=(1000,-900)   D=(-600,900)
E=(-800,-1000)   F=(1000,-800)
```

预先准备三张长度 100 的表，输入 n、m、k 时分别取前 n、m、k 项：

1. 圆：按 x 从 -10 到 10、内层 y 从 -10 到 10 的顺序枚举圆心 `(x,y)`，半径全部为 990；只保留前 100 个。
2. 三角形：i 从 1 到 100，三个顶点取 `(-900+i,-1000)`、`(1000,-900+i)`、`(-600-i,900-i)`。
3. 直线：i 从 1 到 100，用 `(-800+i,-1000)` 和 `(1000,-800+i)` 两个点确定。

三角形的三个顶点沿不同方向移动，使两份三角形形成交错，而不是简单平移后只交两次。直线的两端也沿不同方向移动，从而改变斜率，避免平行。各三角形的顶点位于圆外，三条边又都深入圆内，因而每边能穿过圆两次。

所有输出坐标都在允许范围内，圆半径也合法。注意圆心的枚举顺序是构造的一部分；不要随意换成任意的 100 个整数点后仍沿用这里的校验结论。

## 怎样确认没有三条边界共点

“随机扰动大概率没问题”不足以证明这个固定整数构造。工程中的 `scripts/validate_nanjing_geometry_2025.py` 对完整的 100+100+100 组图形做了整数穷举检查。任何较小输入都是这组构造的子集，因此完整集合通过后，所有合法输入的坐标构造也都成立。

检查分为四种三重相交情形，涵盖所有可能：

- 三条直线或三角形边：用整数叉积求交。把有理数交点统一写成互素的 `(X,Y,W)`，表示 `(X/W,Y/W)`；若不同的边对得到同一点，就能发现共点。三角形自己的两个邻边相交是合法顶点，但该点不能再落在第三条边界上。
- 一个圆、两条直边：枚举上一步的交点，代入 `(X-cx*W)^2+(Y-cy*W)^2=990^2*W^2`。全部用整数，不依赖浮点误差。
- 两个圆、一条直边：先把两个圆的方程相减，得到根轴直线；将根轴与直边求交，再代回圆方程。还要单独排除根轴与直边重合。
- 三个圆：两个根轴的交点是唯一候选，再代入圆方程；圆心共线时不存在三圆公共点。

校验还逐对检查表中的最大交点数，并排除相切、端点落在圆上等情形。圆与线段相交两次的充分判据是：两端都在圆外、圆心到支撑直线的距离严格小于半径，且垂足在线段内部。

这是一种针对有限固定表的完整构造验证；它没有把几百万次随机实验当作证明。源码随工程保留，可以重新运行。校验脚本的复杂度较高，但它只用于验证固定表，提交程序不需要运行它。

## 实现骨架与复杂度

```text
读入 T
重复 T 次：
    读入 n,m,k
    P = n*(n-1) + 3*m*(m-1) + k*(k-1)/2
        + 6*n*m + 2*n*k + 2*m*k
    输出 P+k-(k>0)+2
    按 x、y 的固定双重循环输出前 n 个 (x,y,990)
    对 i=1..m 输出 (-900+i,-1000, 1000,-900+i, -600-i,900-i)
    对 i=1..k 输出 (-800+i,-1000, 1000,-800+i)
```

注意在输出第 n 个圆后退出整个圆心枚举，或先建好 100 项数组。特别是 n=0 时不要误输出一行。三角形输出的是三个点，直线输出的是两个点；直线延伸到无穷远，不要把它当作只连接所输出两点的线段。

每组时间 O(n+m+k)，除输出外额外空间 O(1)，也可存三张常数大小的表。答案用 64 位整数即可。所有整数运算都先提升类型再相乘是良好习惯；校验程序中的大整数只服务于精确几何验证，不代表提交程序也需要大整数。
