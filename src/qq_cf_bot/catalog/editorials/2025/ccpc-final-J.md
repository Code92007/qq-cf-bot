# J · Slay the Spire 2（杀戮尖塔 2）

## 题意与规模

第 i 回合先增加 x[i] 层毒，然后可以选择是否把触媒层数增加 1。触媒累积保留，回合末触发“当前触媒层数”次毒：每次若毒为 p>0，就造成 p 伤害并把毒减 1；毒为 0 时没有效果。求 n 回合总伤害的最大值。n≤5000，所有测试的 n² 之和≤10^8，允许 O(n²)。

## 先学什么

需要前缀和、等差数列求和、贪心交换论证和 64 位整数。先写一个模拟器：给定在哪几回合加触媒，计算总伤害。特别要理解“早加触媒”并非总更好：早触发会降低剩余毒，可能减少未来许多次高伤害触发。

## 官方性质：只需要两类策略

把加触媒记为 1，不加记为 0。存在一种最优策略，它是：

- `000…0111…1`，即某个后缀每回合都加；
- 上述后缀中跳过一个回合，即 `000…011…101…1`。

以下解释为什么可以压缩成这种形状，然后把第二类的计算化成公式。

## 把复杂过程变成两种交换

最后一回合若为 0，把它改成 1 不会影响后续，且只可能多造成伤害，故可以让最后一位为 1。

考虑一处 `10`，把它改成 `01`，等价于删除前一回合的最后一次触发，其后各回合触媒层数保持不变。

如果原策略从这个时刻开始，后面存在一次毒已为 0 的失败触发，那么延后这一次触发不会变差。原因是原来被消耗的一层毒在中间成功触发中每次多贡献 1，直到它在原来的失败触发处被消耗掉；中途新加入的毒只会使这段额外贡献更多。损失的早期伤害能够被这段贡献抵消。

如果后面没有失败触发，再考虑更后面一处不重叠的 `01`。同时把前者 `10→01`、后者 `01→10`：总触发数不变，只把一次触发从较早回合搬到较晚回合。后面会用公式证明，它增加的伤害是这两回合之间新增的毒总量，故非负。

反复调整，内部不能再有两个可消去的 0；连在一起的两个 0、以及分开的两个 0，都能提供上述两个不重叠的边界。剩下的形式就是纯后缀或后缀中去掉一个 1。对于第二类，如果还存在失败触发，第一种交换又能把它调整成不差的纯后缀。因此只需精确模拟纯后缀，并在“所有触发都成功”的模型中计算缺一项的后缀。

## 没有失败触发时，总伤害有一个短公式

令 `S[t]=x[1]+…+x[t]`，c[t] 为第 t 回合的触媒层数，总触发数为 `C=sum c[t]`。

假设触发永远成功。第 k 次触发发生于第 t 回合时，已经扣掉 k−1 层毒，所以造成 `S[t]−(k−1)` 伤害。所有触发相加：

```text
总伤害 = sum(c[t]*S[t]) - C*(C-1)/2。
```

这也解释了前面的交换：总触发数 C 不变，把一次触发从 i 搬到 j，只让第一项增加 `S[j]−S[i]>=0`。

## 纯后缀：直接 O(n²) 模拟

枚举开始加触媒的回合 s。s 之前没有触发，所以初始毒量为 `S[s−1]`。从 t=s 开始，触媒为 `t−s+1`。设回合加入新毒后的毒量为 p，本回合实际成功次数 `k=min(p,t−s+1)`，伤害为

```text
k*p - k*(k-1)/2，回合结束剩 p-k 层毒。
```

每个 s 扫描到 n，总时间 O(n²)。不要把每次触发单独模拟，否则会多一层循环。

## 后缀去一点：每个方案 O(1)

后缀从 s 开始，长度 d=n−s+1。未去点时：

```text
C = d*(d+1)/2
W[s] = sum(t=s..n) (t-s+1)*S[t]
```

若第 j 回合不增加触媒，那么从 j 到 n 的每回合都少触发一次，因此

```text
C' = C - (n-j+1)
W' = W[s] - sum(t=j..n) S[t]
候选伤害 = W' - C'*(C'-1)/2。
```

预处理 `tail[j]=sum(t=j..n) S[t]`，再从右到左算 `W[s]=W[s+1]+tail[s]`。枚举 s、j，单个候选只需常数运算。

这里故意允许公式把毒扣成负数。这样得到的伤害是实际策略伤害的下界：真实规则在毒不足时会跳过触发，既不会造成负伤害，也不会把负的毒债带到以后。若最优的缺一点方案有失败触发，前述性质保证纯后缀已经覆盖它；若没有，公式恰好等于它。故把全部公式值与纯后缀精确模拟的最大值一起取 max，恰好得到真正最优值。

## 复杂度、边界与验证

时间 O(n²)，额外空间 O(n)。答案和乘法中间值用 64 位整数：S[t] 可达 5×10^10，触发总数约 1.25×10^7。全零输入答案为 0；n=1 时直接触发一次即可，答案为 x[1]。

本工程枚举小规模的全部 2^n 种触媒选择并按原题精确模拟，与上述两类策略算法对拍；同时检查“允许负毒”的公式不超过真实模拟值。验证报告列出实际执行的样本数，没有提交在线评测。
