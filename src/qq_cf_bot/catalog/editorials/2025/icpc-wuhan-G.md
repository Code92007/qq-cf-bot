# G · Projection

## 先学什么

先学单调函数二分、逐坐标裁剪，以及平方配方。理解凸优化会更容易看懂官方KKT推导，但下面给出一个只用“加惩罚项再配方”的最优性证明，可以不先背KKT条件。

## 题意

求距离x最近的点y，同时满足 sum(y[i]²)≤R² 和 |y[i]|≤l[i]。n总和≤10^5，输入a就是R²，不是R；|x[i]|≤10^9，1≤l[i]≤100。

## 先做盒子的投影

若只限制每个坐标范围，最优就是 z[i]=clamp(x[i],-l[i],l[i])，因为各坐标的平方距离可以独立最小化。若sum(z²)≤R²，z也满足球约束，在更大的盒子内都已最优，在交集中当然最优。

否则球约束必须起作用，不能简单把z整体缩小：有些原本被裁剪的坐标需要继续卡在边界，而其他坐标先缩小。

## 为什么是“先缩放原x，再裁剪”

引入µ≥0，在盒子里最小化

```text
F(y)+µ*||y||²，F(y)=sum((y[i]-x[i])²)
```

逐坐标配方后，与y相关的部分是

```text
(1+µ)*(y[i]-x[i]/(1+µ))²
```

所以其最小点为 y[i]=clamp(x[i]/(1+µ),-l[i],l[i])。令t=1/(1+µ)，得到统一缩放形式。

假设选到µ使||y||²=R²。对任意可行点z，由惩罚目标最优性

```text
F(z)+µ*||z||² >= F(y)+µ*R²
F(z) >= F(y)+µ*(R²-||z||²) >= F(y)
```

因此y确实是原题的全局最近点，不只是某个局部驻点。

## 在[0,1]二分t

f(t)=sum(clamp(t*x[i],-l[i],l[i])²)连续单调不减，f(0)=0，而当前分支f(1)>R²。因此二分可找到边界。

```text
lo=0，hi=1
重复80~90次：
    mid=(lo+hi)/2
    若 f(mid)<=R²：lo=mid
    否则：hi=mid
输出 clamp(lo*x[i],-l[i],l[i])
```

保留lo为可行端可以减少浮点误差导致的越界。用long double并输出12位以上小数。即使缩放系数很小，90轮对本题坐标范围也有充分精度。

## 例子与复杂度

x=(3,3,3)、l=(2,2,2)、R²=6，盒子投影(2,2,2)超出球；最终t=√2/3，得到三个√2。若x=(1,10)、l=(4,4)、R²=25，盒子投影(1,4)已在球内，直接返回，不能强行拉到球面。

时间O(n log(1/ε))，固定90轮时O(90n)，空间O(n)。工程对小维度枚举所有可能饱和面的解析候选点，比较目标值并检查边界可行性。尚未在线提交。
