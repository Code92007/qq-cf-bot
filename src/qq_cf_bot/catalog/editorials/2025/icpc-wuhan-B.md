# B · 77G Network

## 先学什么

先学2-SAT：一个布尔变量对应真假两个点，子句转成蕴含边，强连通分量判断冲突。再学DFS序将子树变成区间，以及线段树压缩“一个点连一段点”的边。建议先写小规模暴力建图版，再加入压缩结构。

## 题意

根树有n≤2×10^5个点，选一些点建基站，每条边至少一端被选。故障(x,y)规定：若选x，则x子树中距离x恰好y的点全不能选。故障数≤2×10^5，需输出合法集合或No。

## 先转成2-SAT

令Xu表示选择u。

树边(u,v)产生子句 Xu∨Xv，蕴含边为 ¬Xu→Xv、¬Xv→Xu。

故障涉及的每个u产生子句 ¬Xx∨¬Xu，蕴含边为 Xx→¬Xu、Xu→¬Xx。不能只加第一条：2-SAT子句的两个方向都必须保留。

若直接枚举故障影响的全部点，最坏边数达到O(nm)，需要压缩。

## 精确距离与子树条件合成一个区间

DFS计算tin、tout、depth，子树是半开区间[tin[x],tout[x])。按深度将节点分组，并在每组按tin排序。

故障目标深度d=depth[x]+y。对该组的tin二分，找到落在子树区间中的节点范围[l,r)。这恰好是全部被故障影响的节点；深度不存在或区间为空则跳过。父亲编号小于孩子不代表子树标签连续，不能用原节点编号替代DFS序。

## 两种方向的线段树

对每个深度组建两棵结构相同的树，辅助节点仅用于有向路径压缩：

- 向下树：父辅助点→子辅助点，叶辅助点→对应变量的假点¬Xu。
- 向上树：对应变量的真点Xu→叶辅助点，子辅助点→父辅助点。

将[l,r)拆成O(log n)个标准线段树节点。对每个块v，加入

```text
Xx → down[v]
up[v] → ¬Xx
```

第一条能到达块内所有¬Xu，第二条能被块内所有Xu到达。两个结构不能混用，否则会产生本来不存在的点间蕴含。

## SCC判断与构造

在完整有向图上求SCC。若某个原变量Xu与¬Xu在同一SCC，无解。辅助节点不需要各配一个“取反点”，也不参与变量冲突检查；它们的任务仅是保持原变量之间的可达关系。

凝聚图按源到汇的拓扑顺序编号时，令Xu为真当且仅当 comp[Xu]>comp[¬Xu]。若使用Tarjan自带编号，编号方向可能相反，必须按自己的实现调整；最可靠的做法是明确保证SCC编号沿跨分量边递增。

压缩图在原真假节点之间的路径恰好对应暴力蕴含图路径，因此可满足性不变，所得赋值满足所有树边和故障子句。

## 复杂度与实现

各深度组的叶子总数为n，所以两类树总辅助点、内部边为O(n)，故障新增O(m log n)边。总时间O(n+m log n)，空间同阶，包含SCC与二分。使用扁平邻接表或预留容量避免数百万条边的分配开销；DFS与SCC都建议迭代实现以避免长链爆栈。

工程随机生成小树和重复/越深故障，枚举所有基站子集求真实可行性，并逐条验证压缩图输出的选择。尚未在线提交。
