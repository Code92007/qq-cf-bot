# C · Crossing River

## 先学什么

先学排序与交换论证，再练习倒序安排任务：当最后时刻固定时，应把哪件事放在最晚的位置？本题不需要复杂 DP。先处理两岸各两人的例子，区分相邻两位乘客同岸时需 2k、异岸时需 k。

## 题目与限制

左右岸分别 n,m<=100000 人，每人有到达时间。船单程固定耗时 k<=10^9，一次至多载一人，允许空船过河，可自选起始岸。求全部送达的最早时刻，并输出每名乘客的上船时刻、原岸和原编号。

## 同岸乘客按到达时间顺序运输

若较晚到达的人在前、较早到达的人在后，交换两人的身份不会让任何人提前到达前上船。因此每岸按 `(到达时间,原编号)` 排序，只需决定左右岸乘客如何交错。

正着贪心容易为“要不要等对岸的人”纠结。反过来，枚举最后一位乘客来自哪一岸，倒着确定运输顺序。倒序时船的每趟出发岸必须交替；来到某岸的一个运输机会，如果该岸还有人，就安排尚未安排的最晚到达人。若该岸已无人，放一次空船即可。

## 为什么倒序能贪心填满

设存在某个在时刻 T 前完成的方案。把最后一次送人的行程向后推到恰好 T 结束不会违反到达限制。再从后向前看，若某一趟可以载某岸乘客却空着，而更早有该岸乘客，把那个较晚到达的乘客挪到这趟即可：它上船更晚，且船的岸别、其他行程都不变。若已经载人，也可交换成该岸尚未处理的最晚到达人。

不断执行交换，任何可行方案都可改为我们的倒序顺序。因此，固定最后岸后，这个顺序不会丢失最优解。

## 不必二分时间

具体实现时，先分别得到“最后来自左岸”和“最后来自右岸”的乘客顺序：倒序轮流从两岸排序数组末尾取人；某岸空时跳过它，继续另一岸。取完反转序列。

然后正向计算这个顺序的最早上船时间。第一人的上船时刻就是其到达时间；之后

```text
同岸：t = max(该人的到达时刻, 上次上船时刻+2*k)
异岸：t = max(该人的到达时刻, 上次上船时刻+k)
```

最终完成时刻为最后 t+k。取两种最后岸中的较优方案。空船不用输出，已经体现在 2k 的间隔里。

## 例子与边界

左岸到达 `[1,100]`，右岸 `[2]`，k=1。最后来自左岸时，倒序选左100、右2、左1；正序上船时刻为 1、2、100，完成于101。等待到100是必要的，不能假定船始终连续工作。

固定顺序时，每一步选尽可能早的上船时刻不妨碍之后的人，因此正向递推是该顺序的最优时间。结合倒序交换论证和两种末岸枚举即得全局最优。排序 O(n log n+m log m)，模拟 O(n+m)，空间 O(n+m)。答案可能达约 4*10^14，全部时间用 64 位；排序后仍要输出原编号。
