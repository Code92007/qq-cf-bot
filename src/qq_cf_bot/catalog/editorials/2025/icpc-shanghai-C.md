# C · Singularity

## 先学什么

先学排列、逆序、按中位数二分值域、前缀和以及构造中的倍增势能。建议先手动执行一次 FakeSort：它分别排序区间里较小的一半和较大的一半，但两类所占位置不变。本题不能把 FakeSort 当作普通区间排序；长度为 2 的操作甚至什么都不做。

## 从排列转到 01 串，但不能忘记真实值

把 ≤n/2 的数标成 0，其余标成 1。若能让标记变成前 n/2 个 0、后 n/2 个 1，再执行 FakeSort(1,n)，两类内部都会排好，整个排列即有序。

全局 FakeSort 不改变这份 01 标记，只会让所有 0 内部、所有 1 内部分别递增。后面称它为 N 操作。必须同步模拟真实排列，因为对子区间 FakeSort 的分组中位数与全局 n/2 不一定相同。

## 哪种串完全无法改变

如果标记严格交错，任何偶数长度区间都恰好一半 0、一半 1，FakeSort 只会在各自位置里排序，永远不能改变标记，因此无解。

令 b[i] 在大数处为 +1、小数处为 -1，前缀和 c[0]=0。当所有前缀和的最大值与最小值之差≤1 时，恰好是这种交错情况。

n=4、6 还存在短长度特例。为了避免把“大 n 的结论”错误套到它们，可以直接对真实排列 BFS：节点是一种排列，边是一次合法 FakeSort，寻找有序排列。最多 6!=720 个状态，所有长度为 2 的无效操作可跳过；不可达就输出 -1。

## 一个区间排序子过程

维护偶数长度区间 [l,r]。交替执行 N 与 FakeSort(l,r)，直到区间的 01 标记已经非降。

若本阶段希望把小数固定在左端，每轮去掉开头连续的偶数个 0；若希望把大数固定在右端，每轮去掉末尾连续的偶数个 1。删去这里只是缩小下一轮操作范围，已经固定的位置仍在原排列中。

记这个过程为 `Work(l,r,side)`，side=L 表示剥去左端 0 对，side=R 表示剥去右端 1 对。

为什么能倍增？假设活动区间中两类数量差为 2d。经过 N 后同类真实数值有序；局部 FakeSort 的“较小一半/较大一半”会跨越全局两类的分界，使 d 个原本混在错误位置的数跨到另一类的位置。剥去已经整理好的偶数长边界后，剩余活动部分的数量偏差至少翻倍。初始偏差非零时，最多 O(log n) 轮即可耗尽混杂部分。

## 怎样制造非零偏差

从左往右寻找第一次满足 |c[i]|≥2 的前缀；此时恰好 |c[i]|=2，它的长度 i 必为偶数。如果所有前缀和都在 {-1,0,1}，但不是严格交错，就会同时出现 +1 和 -1。

对 n≥8，可以找到一对前缀下标 u&lt;v，c[u] 与 c[v] 一正一负、绝对值都为 1，且 v-u≥4。先做 N，再做 FakeSort(u+1,v)，即可产生绝对值至少 2 的前缀。可扫描时记录每种符号最早出现的位置；不必 O(n²) 枚举。

完成后重新计算 c，选第一个绝对值达到 2 的 i。这里的重新计算不能省略。

## 两阶段整理及边界修补

下面给出与官方构造一致的确定流程。每个 FakeSort 都作用在当前真实排列上，检查“0/1”时按当前值是否≤n/2判断。

- c[i]=-2：执行 Work(1,i,R)，再执行 Work(3,n,L)。
- c[i]=+2 且 i>n/2：执行 Work(1,i,L)，再做 N。若位置 2 仍是 1，从 p=i+1 开始，当 p+1 仍是 1 时递增 p；p 为奇数时做 FakeSort(2,p)，否则做 FakeSort(1,p)。然后执行 Work(3,n,L)。
- c[i]=+2 且 i≤n/2：执行 Work(i+1,n,R)，再做 N。若位置 n-1 仍是 0，从 p=i 开始向左找到第一个 1；若 n-p 为奇数，做 FakeSort(p,n)，否则做 FakeSort(p,n-1)。然后执行 Work(1,n-2,R)。

最后再做一次 N。修补操作的目的，是保证两端待固定的位置有一整对正确标记；省略它会在很短的首段或尾段上失败。三个分支的区间长度均为偶数。

## 怎样正确模拟 FakeSort

收集区间内的数，按值排序，找到中位分界。记录各位置在操作前属于较小组还是较大组，然后按位置递增依次填入对应组的递增值。不能边写边重新判断组别。

由于输入是 1..n 的排列，也可以给出现的值打标记，再扫描整个值域得到有序列表，一次模拟 O(n)。两次 Work 各需要 O(log n) 轮，每轮两个操作，加上常数次预处理、修补与收尾，总次数远低于 114；总模拟时间 O(n log n)，空间 O(n)。

## 必须做的构造自检

这题的主要风险是构造细节。输出前应确认所有操作区间长度为偶数、操作数≤114、模拟后的排列确实为 1..n。小 n 用完整 BFS 对比是否存在解；较大 n 随机测试并覆盖“几乎交错”“第一个不平衡前缀很短”“大数过半”和“小数过半”。若实现只写了“多执行几次应该会好”，它还不是一个有界构造。
