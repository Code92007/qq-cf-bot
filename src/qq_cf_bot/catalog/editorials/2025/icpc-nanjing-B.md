# B · 什么，还有袋鼠？

## 先学什么

学习顺序是：向量点积的正负 → 叉积与极角排序 → 环形双指针。先回答：同一个向量乘以正数，方向会不会改变？两个向量的夹角小于 90 度时点积是什么符号？本题不需要求半平面交的多边形，也不用真的找出所有按钮的按法。

## 四个按钮只留下两个整数

设按 1 的次数减按 2 的次数为 x，按 3 的次数减按 4 的次数为 y。任意整数 x、y 都能通过非负次数的按键实现。第 i 只袋鼠最终位置是

`a[i]*x+b[i]*y+c[i]`。

因此问题是选择一个整点 (x,y)，让尽量多的不等式严格小于 0。若 a=b=0，袋鼠永远留在正坐标，可以直接丢弃。

## 为什么初始位置 c 可以暂时不管

固定一个非零方向 v=(x,y)。沿这个方向走到 t*v：

- 若 (a,b)·v≥0，加上正数 c 后永远不可能小于 0。
- 若 (a,b)·v&lt;0，只要正整数 t 足够大，就能压过 c。

袋鼠只有有限只，对所有负点积袋鼠的阈值取最大值即可。因此最优数量就是：一个方向能与多少个向量形成严格负点积。c 影响需要按多少次按钮，但不影响最大数量。

实数方向是否会比整数方向更强？不会。某个方向使有限个点积严格为负，则附近一小段角度仍全为负。斜率为有理数的方向在角度上稠密，可选一个有理方向，乘公分母得到整向量，再充分放大。

## 转成开半圆内最多有几个向量

与固定方向负点积的所有向量，恰好落在某个角度长度为 π 的开半圆中。因此把所有非零 (a,b) 按极角排序，寻找角宽严格小于 π 的最长连续段。

排序不要依赖 atan2 的浮点相等。先按上半平面分组，例如 `y>0 或 (y==0 且 x>0)` 放前面，同组用叉积大于 0 比较。相同方向保留重复项，因为它们代表不同袋鼠。为避免绕一圈后同方向被误收，把相同方向先聚合为一个组及其数量，再复制组序列一遍。

对每个起点 l，右端 r 只向前走，最多走完一圈。首组必收；随后只在 `cross(v[l],v[r])>0` 时收组。叉积为 0 的反向组不能收；同向组已合并，复制后再次出现也必须由一圈长度限制排除。维护窗口数量之和，取最大值。如果只有一组，答案就是该组数量。

## 严格性与例子

若只有 (1,0) 和 (-1,0)，任何方向至多让一个点积为负，答案是 1。不能因为“180 度以内”而把两个相反方向都放入窗口。

若三个向量都为 (1,1)，把方向取 (-1,-1)，放大后全能移到负坐标，所以重复方向应贡献 3，不能去重后忘记其权重。

窗口描述了某个开半圆；反过来，每个可行方向对应这样的窗口，所以最大窗口正是答案。排序 O(n log n)，双指针 O(n)，空间 O(n)。叉积中单项可达 10^18，差值可达 2×10^18，使用有符号 64 位；用 128 位做比较也很稳妥。
