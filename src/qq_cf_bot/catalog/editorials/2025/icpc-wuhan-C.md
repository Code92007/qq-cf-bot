# C · Not Aqre

## 先学什么

先学网格八连通（允许对角相邻）、构造中的周期模式与转置。这里必须同时检查数量、横竖连续三个、每种颜色整体连通；仅凭图看起来交错不能证明正确。

## 题意

n×m格子填0、1、2，各出现nm/3次；横竖不能连续三个相同；每种数字的格子必须八连通。已保证nm被3整除，维度≤1000，总格数≤10^6。

先允许转置，使较小维度h≤w。最终按是否转置还原输出。

## 窄板的完整处理

h=1或2时，w必为3的倍数：

- w=3：每行填012。
- w=6：每行填001122。
- w≥9：No。

一行时每种颜色连通意味着一个连续段，数量至少3就违反规则。两行时，设左上角为0：若0还出现在最后两列，连接它们至少需w-1个0，多于2w/3，所以最后两列没有0。前两列不能全为0，否则第3列因横向限制无0，左侧0连通块最多4个，小于所需2w/3。因此前两列必出现另一种颜色，记1。最后两列又必须同时有1和2：若全为某一种，该色同样被第三倒数列隔断而不足额。于是1从前两列连到最后两列，至少需w-2个格子，仍大于2w/3，矛盾。

## 3行基本块

按列重复以下长度6周期，截取所需宽度：

```text
220011220011...
102102102102...
011220011220...
```

每列三色各一次，所以数量自动相等。每行没有三个连续相同，列中三色不同。沿着对角连接观察，每种颜色形成一条从左向右延伸的连通带；宽度3、4也可以直接检查成立。

h=3时直接用这个块，适用于任意w≥3。

## 4行特殊块

h=4时，w必为3的倍数，使用

```text
220011220011...
102102102102...
102102102102...
011220011220...
```

中间行重复后仍没有竖向三个相同；当w是3的倍数，中间行三色数量相等，所以整体各色仍为4w/3。原3行块的对角连通带通过重复中间行相接，仍连通。

## 其余尺寸怎样铺

当两维都≥5时，至少一维是3的倍数。必要时再转置，使行数H被3整除，宽度W≥5。

每3行放一个基本块，相邻块交替使用正常顺序和上下翻转顺序：

```text
第0块：上行、中行、下行
第1块：下行、中行、上行
第2块：上行、中行、下行
...
```

边界上两行相同，只形成长度2的竖向重复，其外侧相邻行与它逐列不同，不会形成三个。宽度≥5时基本块的上行、下行都包含三种颜色，因而每种颜色都能在每个块边界直接连接，所有块合成一个连通区域。

宽度3或4不能盲目叠加：某条边界行可能缺一种颜色，产生断裂；前面的h=3、h=4特殊处理正是为避免这个问题。

## 复杂度与验证

构造、转置输出均O(nm)，空间O(nm)。以数字字符输出时遵从平台格式即可；不需要随机搜索。工程对1..60的全部可行尺寸逐格核验三色计数、横竖限制及真正的八邻接BFS连通性。无解窄板依据上述证明。尚未在线提交。
