# H · Hextech High-roll

## 先学什么

先学不放回抽样、条件期望和组合数。再练习“先观察结果，再在两个动作中选期望较大者”；这与事先固定重抽次数不同。浮点实现使用 double 或 long double，组合数本身不要用整数直接计算。

## 题意

屏幕有 k 张牌，值为 a；牌堆有 n 张牌，值为 b，k≤n≤10^5，绝对值≤10^5。每个卡槽最多重抽一次，不放回，看到结果后可以继续或停止。最后选屏幕最大值，求最优期望。

## 为什么至少可以先重抽 k-1 次

留下一个初始最大值 A=max(a)。其他卡槽即使抽得很差，A 仍在，因而这些重抽不会降低最终收益；还会带来新信息。所以存在一个最优策略，先把其余 k-1 个卡槽全部抽完。

更一般地，不必先刷新最大的原始牌：与刷新一个较小的未刷新槽交换顺序，能够保留更强的兜底值，而且抽到的牌分布不变。重复交换后，初始最大值总可留到最后。

## 观察后作最后一个决策

将 b 按值排序为 b[1]≤…≤b[n]；相等值仍按不同实体卡的编号区分。设前 k-1 次抽到的最大下标为 j，B=b[j]。

停止的收益为 max(A,B)。若刷新最后一个槽，还剩 n-k+1 张牌：

- 在下标≤j 的 j 张牌中，已经抽掉 k-1 张，剩下 j-k+1 张。抽到它们时，B 仍是屏幕最大值。
- 下标>j 的牌一张没抽过，抽到 b[t] 时最终最大值是 b[t]。

故继续的条件期望为

```text
R[j] = ((j-k+1)*b[j] + sum(b[j+1..n])) / (n-k+1)
V[j] = max(A, b[j], R[j])
```

最后一项 max 表示在看到前 k-1 次结果之后选择较优动作，不能先对所有情况求平均再决定。

## 每种最大下标的概率

前 k-1 张牌形成一个均匀随机子集。最大下标是 j 当且仅当包含 j，并从前 j-1 张中选 k-2 张，因此

```text
P[j] = C(j-1,k-2) / C(n,k-1),  j=k-1..n
answer = sum(P[j]*V[j])
```

概率可以从右向左稳定递推：

```text
P[n] = (k-1)/n
P[j-1] = P[j] * (j-k+1)/(j-1)
```

官方讲义第32页第二式的分子写成 j-k，少了 1；按相邻组合数相除应为这里的 j-k+1。例如 k=2 时只抽一张牌，每个下标的概率都必须是 1/n；修正后的比值为 1，原式不满足这一基本检查。

## 特殊情况与例子

k=1 时没有“前 k-1 次抽样”，直接输出 max(a[1],平均 b)，避免 k-2 为负数。

例如 A=5、k=2、牌堆 [1,4,10]。先抽到 1 时，继续期望为 (4+10)/2=7，胜过保留5；先抽到4时，继续期望为 (4+10)/2=7；先抽到10时，已经保留10，刷新最后一槽也不会下降。答案为 (7+7+10)/3=8。

## 正确性、复杂度与实现

交换论证保证先刷新非最大槽不损失最优性；完成这些刷新后，剩余动作只有停止或刷新最后槽，条件期望枚举已包含全部选择；对互斥的最大下标事件加权，得到全局最优期望。

排序 O(n log n)，后缀和与概率扫描 O(n)，空间 O(n)。后缀和用 64 位整数；概率和收益用 long double。建议完整扫描所有 j，不必为了微小优化过早截断尾部概率。所有 b 都可能为负，不能把最大值或答案初始为0。

工程用有理数枚举所有可选刷新槽、所有抽牌结果和停止动作，直接求小规模最优策略，与该公式对拍，包含重复值、负值和 k=1。尚未在线提交。
