# I · Round screws

## 先学什么

需要动态规划、按二进制位理解异或、值域分块。先证明 `x xor z <= (x xor y)+(y xor z)`：每一位只要 x、z 不同，途经 y 时至少要变化一次；额外变化只会增加非负代价。这个“三角不等式”是删除中间修改值的依据。

## 把首尾代价也变成边

增加两个不能修改的哨兵 `a[0]=a[n+1]=0`。序列价值就统一写成相邻值的异或和，包括两端与 0 的边。

选择哪些位置保留原数。两个相邻保留位置 j&lt;i 之间，其余 i-j-1 个位置都修改，需要代价 `(i-j-1)C`。由异或的三角不等式，中间怎么填写，相邻异或和至少是 `a[j] xor a[i]`；把所有修改位置填成 a[j] 就能达到这个下界。

所以不用考虑任意大的修改值，只用决定保留哪些位置。

## 朴素 DP

令 f[i] 为处理到保留位置 i 的最小总代价，f[0]=0，则

`f[i]=min(j<i) {f[j]+(i-j-1)C+(a[j] xor a[i])}`。

答案 f[n+1]。这也包含把全部真实元素改成 0 的方案，其代价为 nC。朴素转移 O(n²)，要优化的是两值异或这一项。

## 把 18 位拆成高 9 位、低 9 位

设 `a=512*high+low`。异或没有进位，所以

`a[j] xor a[i] = 512*(high[j] xor high[i]) + (low[j] xor low[i])`。

维护长度 2^18 的表 best。表项 best[512*h+l] 表示：所有已加入的 j 中，高位等于 h 时，`f[j]-(j+1)C+(low[j] xor l)` 的最小值。

加入一个 j，只要枚举目标低位 l=0..511：

```text
best[512*high[j]+l] = min(
    best[512*high[j]+l],
    f[j]-(j+1)*C+(low[j] xor l))
```

计算 f[i] 时枚举前驱高位 h=0..511：

`f[i] = i*C + min_h {best[512*h+low[i]] + 512*(h xor high[i])}`。

一个方向把低位的代价预处理进去，另一个方向枚举高位，不必同时枚举全部 2^18 个值。

## 顺序和边界不能错

初始化所有 best 为 INF，先加入 j=0。接着 i=1..n+1：先查询 f[i]，若 i≤n 再把当前 i 加入表。不能先加入再查询，否则允许 j=i，自环会多减一次 C，得到虚假的更小值。

例子 a=[1,2]、C=0：可以全部修改成 0，答案为 0。若 C 很大，最优可能完全不改，f 会自动选择每个原位置，得到 `1+(1 xor 2)+2=6`。

## 正确性与复杂度

任意修改方案都能压缩成保留位置链，并由三角不等式下界覆盖；每条 DP 链又能通过把间隙填成左端值达到，所以 DP 与原问题等价。高低位拆分只是对每个 j 的同一个代价重新分组，查询仍枚举全部前驱高位，没有丢掉方案。

时间 O(n·2^9+2^18)，空间 O(2^18+n)，f 也可以不完整保存以降到 O(2^18)。本题多组数据，总 n≤2×10^5；每组需要重置表，不能遗留前一组状态。f、best 中可能出现负中间值，应使用有符号 64 位，INF 的加减要留足余量。
