# C · 分糖果

## 先学什么

只需要正整数、整除和奇偶性。整除 `a | n` 的意思是 n 除以 a 的余数为 0，并不是 a 比 n 小就够了。可以先用 n=6、a=2、b=4 检查：虽然两者相加是 6，但 4 不能整除 6。

## 两个要求一起使用

题目要求正整数 a、b 满足 a+b=n，而且 a、b 都整除 n。

如果 n 为奇数，a 和 b 中必定有一个是偶数。可是任何偶数乘整数仍是偶数，不可能得到奇数 n。于是这个偶数不可能整除 n，矛盾。因此奇数一定无解，包括 n=1。

如果 n 为偶数，直接令 a=b=n/2。两者都是正整数，相加为 n，而且 n 是它们的两倍，所以两次整除条件同时成立。

这既证明了无解情况，也给出了所有有解情况的构造。无需分解质因数、枚举因子或寻找不相等的两份；题目允许 a=b。

## 实现

```text
读入 n
若 n 为奇数：输出 No
否则：输出 Yes，再输出 n/2 和 n/2
```

例如 n=2 输出 1、1；n=6 输出 3、3；n=7 输出 No。n 最大为 10^18，C++ 使用 `long long`，不要把输入先读进 int 再转型。每组 O(1) 时间、O(1) 额外空间。

## 如果还没理解证明

试着补完这句话：“假设 n=9 有解。由于 a+b 是奇数，其中一个数是偶数，设它等于 2k。若它整除 9，就存在整数 q 使 9=2kq。但右边一定是____，矛盾。”能填出“偶数”，就掌握了本题反证的关键。
