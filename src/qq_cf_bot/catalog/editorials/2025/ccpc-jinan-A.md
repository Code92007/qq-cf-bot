# A · Cipher（暗语）

## 题意与规模

给出 64 位无符号整数 a、b，求最小非负 x 使 `a^x≡b (mod 2^64)`，无解输出 `broken message`。约定 0^0=1，共至多 10^5 组。模数是 2 的幂，不适合直接套通常的质数模离散对数模板。

## 先学什么

按模运算 → 二进制低位 → 快速幂的平方链 → 群中元素的阶学习。需要知道 ctz 是“二进制末尾连续零的个数”。先手算模 16 下 3 的幂：1、3、9、11、1，观察指数某一位如何影响结果的某一位。

## a 为偶数：最多试到 64

偶数每乘一次至少多一个因子 2，所以 a^64 已经是 0 模 2^64。此后仍然是 0。依次检查 x=0,1,…,64 即可，遇到第一个等于 b 的结果就是最小答案。初始幂值必须为 1，这也正确处理 a=0、b=1。

## a 为奇数：依次决定指数的二进制位

维护 `cur=a^x`，初始 x=0、cur=1；第 k 轮维护 `u=a^(2^k)`。选择指数第 k 位为 1，就把 cur 乘以 u。

当 u≠1 时，令 `t=ctz(u−1)`。可以写成 `u=1+q*2^t`，q 为奇数。由于 cur 也是奇数：

```text
cur*u - cur = cur*q*2^t。
```

这说明乘 u 完全不改变第 t 位以下的二进制位，却一定翻转第 t 位。因此检查 cur 与 b 的第 t 位：不同就必须乘 u，相同就必须不乘。

下一轮 u 变成 u²。对奇数 u，`u²−1=(u−1)(u+1)`，u+1 为偶数，所以其最低非零位严格向高位移动。之后的乘法再也不能修改本轮决定的位。这正是逐位贪心成立的原因。

## 为什么必须在最后再次检查相等

最低非零位可能跳过某些位。例如 a=1 时，所有幂都只是 1；a=−1 时只有 1 和 −1 两种值。我们决定的只是“能自由变化的那些位”，被跳过的位也必须与 b 相等。

当平方链第一次出现 u=1，就停止。如果 cur=b，输出 x；否则无解。奇数 a 的阶是 2 的幂，而本算法只决定阶对应的有限个指数位，所以得到的 x 位于 `[0,ord(a))`。其中每个幂值互不相同，故找到的 x 一定是最小非负解。

## 实现框架

```text
cur=1, answer=0, u=a, k=0
while u != 1:
    t=ctz(u-1)
    if ((cur xor b) >> t) & 1:
        cur *= u
        answer |= uint64(1) << k
    u *= u
    k += 1
if cur == b: 输出 answer
else: 输出 broken message
```

这是奇数分支。C++ 的 `uint64_t` 乘法按模 2^64 自然溢出，恰好符合题意；有符号溢出则不能这样使用。`ctz(0)` 没有定义，所以一定先检查 u≠1。不要写 `1<<k`，它可能使用 32 位 int。

每组最多 O(64) 次常数操作，总时间 O(64T)，额外空间 O(1)。b 为偶数而 a 为奇数时一定无解，但最后的相等检查已经能处理。
