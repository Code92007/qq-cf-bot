# G · Make SYSU Great Again IV（贵校是构造王国吗 IV）

## 题意与规模

给定 X≤10^9，构造长度至多 6、每项在 1 到 4000 之间的正整数数组 a，使以相邻两项作为矩阵维度的矩阵链，最优乘法次数恰好等于 X。至多 500 组。

例如 `[1,1,X]` 只有两个矩阵相乘，代价恰好 X，所以 X≤4000 时已经解决。困难在于大 X 不能直接塞进一项，而且“找到一种括号方案代价为 X”还不够，必须保证别的括号方案不会更便宜。

## 先学什么

先学矩阵链乘法区间 DP，再学凸多边形三角剖分与矩阵链的对应关系，最后学习两数互质时的非负整数凑数。可先写六项数组的区间 DP，用它检验每一个构造，成本只有常数级。

## 用六边形安排一个中央三角形

数组可以看成凸多边形各顶点的权值，每个三角形代价是三个顶点权值的乘积，矩阵链最优代价等于最小三角剖分代价。

选择奇数 k≥3，使用顺序

```text
[k, z, k+1, x, k+2, y]。
```

目标剖分把三个较小的顶点 k、k+1、k+2 连成中央三角形，外围各有一个耳三角形。其代价是

```text
k(k+1)(k+2) + (k+1)(k+2)x + k(k+2)y + k(k+1)z。
```

要求 y、z≥k+2，并且 x 满足

```text
1/k + 1/x < 1/(k+1) + 1/(k+2)。
```

最后一个不等式正是中央四边形中选对角线 `(k+1,k+2)` 比选 `(k,x)` 更便宜的条件。取

```text
x0 = floor(k(k+1)(k+2)/(k²−2)) + 1
x=x0+dx，y=k+2+dy，z=k+2+dz。
```

三个增量均非负。

## 如何核实这确实是最优括号方案

六边形只有 14 种三角剖分，可以完整枚举，不能只检查某一种相邻交换。

把各方案的代价减去目标方案，再代入 x=x0+dx、y=k+2+dy、z=k+2+dz，可得到 dx、dy、dz 的多重线性多项式。对于下面使用的每个奇数 k=3,5,…,999，其每一个系数都非负。因此对任意非负增量，所有方案都不比目标便宜。

这给出一个有限、可复现的精确证明检查：499 个 k，每个检查 14 个剖分，共 6986 次整数系数比较，完全不需要浮点数或随机猜测。本工程验证脚本保留了这一步。程序也可以对每个最终数组跑一次六项矩阵链 DP，直接确认输出的实际最优值。

## 剩下是三个系数的非负凑数

默认 x=x0、y=z=k+2 时的代价记为 T。令 R=X−T，需要

```text
R = (k+1)(k+2)dx + k(k+2)dy + k(k+1)dz。
```

先看模 k+1：中间系数 `k(k+2)≡−1`，因此取

```text
dy = (-R) mod (k+1)，使 0<=dy<=k。
```

再令 `N=(R−k(k+2)dy)/(k+1)`，任务变成

```text
(k+2)dx + k*dz = N。
```

k 是奇数，所以 gcd(k,k+2)=1。对 N≥k²−1，一定可以非负表示。一个直接构造为

```text
dx = (N * ((k+1)/2)) mod k
dz = (N−(k+2)dx)/k。
```

这里 `(k+1)/2` 是 2 模 k 的逆元。dx≤k−1，且上面给出的 N 下界保证 dz≥0：即使减去最大的 `(k+2)(k−1)`，结果仍大于 −k；它又是 k 的倍数，所以不可能为负。

## 为每个 k 求出保证可行的 X 区间

为确保减掉最多 k 次中间系数后仍有 N≥k²−1，取下界

```text
low = T + (k+1)(k²−1) + k²(k+2)。
```

为保证构造的每个数≤4000，取上界

```text
high = T + min(
    (k+1)(k+2)(4000−x0),
    k(k+2)(4000−k−2),
    k(k+1)(4000−k−2))。
```

只要 R 不超过这三个容量中的最小值，无论求出的非负解怎样分配，每个单项贡献都≤R，于是其对应增量必不超过允许上限。

对 k=3,5,…,999 预处理这些整数区间，按顺序检查没有断档。第一段从 452 开始，和 `[1,4000]` 的直接构造重叠；合并后覆盖一直延伸到 7001000999，完整包含题目要求的 `[1,10^9]`。这是有限区间的精确覆盖检查，验证脚本同样保留了断言。

每个 X>4000 找到包含它的一段，按上一节求增量，再输出六个权值即可。

## 复杂度与验证

预处理仅 499 个参数；每次顺序寻找区间 O(1000)，之后常数计算。T≤500 时总成本很小。所有代价和乘法使用 64 位，构造中的取模结果规范为非负，尤其是 `(-R)%(k+1)`。

本工程实际检查了全部 6986 个剖分差多项式的非负系数、全部参数区间的无断档覆盖，并对小值、区间边界和随机大值共 26470 个目标运行完整矩阵链 DP。没有提交在线评测。
