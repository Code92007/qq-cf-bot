# B · Buggy Painting Software I

## 先学什么

先学频次统计与交换排序。理解“图层”可以把一个颜色免费铺满全图，代价是其他位置需要擦掉；然后把二维坐标忘掉，只看每种颜色出现多少次。

## 题意

可免费创建纯色或透明图层；画一个像素花a，擦成透明花b。合成图取每格最上方非透明颜色，要求得到目标矩阵。0表示透明。n,m≤500，总格数≤10^6。

## 从任意方案化成统一结构

一个最终被遮住的画笔像素没有作用，可删去。所有最终可见的画笔像素都可搬到最顶层的同一张透明图层，既不增加画笔次数，也免去了上方遮挡。下方因此只需创建纯色层并擦除像素。

同色纯色层重复没有必要：上面那层已能提供该颜色，重复层只增加透明位置的擦除需求。固定纯色层顺序后，颜色位于自上而下第i层，就需擦掉上面i-1层，单个像素花(i-1)b；不由纯色层提供的像素用画笔，花a。

## 为什么频次从大到小排

记透明像素数c0，非零颜色频次降序为 c1≥c2≥…≥ct。两个纯色层若上层频次更小，交换后把较小的擦除系数分给较大的频次，总代价不增加，这是普通的交换论证。

若某层的擦除系数(i-1)b已经大于画笔价a，保留该层只会增加成本，删掉它并改画不会更差。因此最优保留层的系数都≤a；把一个较少见的颜色换成未选的更常见颜色，同样不会更差。故总存在一个最优方案，纯色层恰为频次最大的前k种。

## 枚举层数的公式

透明位置必须擦穿全部k层，所以总费用为

```text
cost(k) = a*sum(c[k+1..t]) + b*k*c0 + b*sum((i-1)*c[i],i=1..k)
```

包含 k=0，它表示全用画笔。初始 cost=a*所有非零格数；逐层增加时只需

```text
cost += b*c0 + (b*(k-1)-a)*c[k]
```

每一步取最小值。

例如目标有8格颜色1、1格颜色2、1格透明，a=5,b=2。全画需45；仅加颜色1纯色层，透明擦一次2、颜色2画一次5，总7；再加颜色2层，透明要擦两层4、颜色2擦一次2，总6。

## 边界与复杂度

全透明时0层费用0。频次为0的颜色不必放入排序；画布布局不影响答案。费用可能到10^12量级，用64位整数。时间 O(nm+t log t)，空间 O(nm) 或颜色计数 O(nm)。工程枚举小频次、全部纯色层有序子集及每种像素的独立最优选择，与公式比较。尚未在线提交。
