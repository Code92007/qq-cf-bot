# L · 交换字母

本文按用户提供的 QOJ 题面截图独立推导。

## 先学什么

学习线性 DP 和状态压缩。先把所有操作看成对字符串的分块：一个不交换的单字符块，或者一个交换内部两字符的双字符块。因为每个位置最多参与一次交换，这些块必须无重叠地覆盖整串。

## 只需记住已输出串的最后一个字符

从左到右消费原串。消费前 $i$ 个字符后，最后一块只可能是：

- 单字符块，最后输出字符为 $s_i$；
- 双字符交换块，最后输出字符为 $s_{i-1}$。

定义 $dp[i][0/1]$ 为这两种情况的最大相邻相等对数。不可达状态设为负无穷，$dp[0][0]=0$；空前缀没有最后字符。

从一个可达状态出发，记已有输出的最后字符为 $c$。

**追加单字符：**不交换 $s_{i+1}$，只增加新边界的贡献：

$$dp[i+1][0]\gets\max(dp[i+1][0],dp[i][t]+[c=s_{i+1}]).$$

**追加双字符：**若还有至少两个字符，交换 $s_{i+1},s_{i+2}$，输出顺序为 $s_{i+2},s_{i+1}$。新贡献包含旧串与新块之间的边界，以及块内边界：

$$dp[i+2][1]\gets\max(dp[i+2][1],dp[i][t]+[c=s_{i+2}]+[s_{i+2}=s_{i+1}]).$$

空前缀与新块之间的边界贡献为零。答案是 $\max(dp[n][0],dp[n][1])$。

## 正确性证明

任意合法交换集合唯一对应一个单字符块和交换双字符块的划分。两种转移恰好枚举下一块的全部可能，因此不会漏掉合法结果，也不会允许重叠交换。

每对相邻输出字符，要么是双字符块的内部边界，要么是相邻两块的连接边界。转移恰好在该边界首次形成时计算一次，既不遗漏也不重复。状态还保留了下一次转移需要的唯一历史信息，即最后输出字符。因此 DP 值及最终最大值均正确。

## 实现与复杂度

使用下标从零开始的原串时，消费 $i$ 个字符后，状态 $t$ 的最后字符是 `s[i-1-t]`；读取前必须保证状态可达且 $i>0$，尤其不要在 $i=0$ 或不可达的交换状态中越界。

时间 $O(n)$，普通数组实现空间 $O(n)$。转移只涉及接下来两个位置，也可以使用三行滚动数组将空间降至 $O(1)$；清空即将重新使用的行后再转移。长度为一时答案自然为零。

## 完整代码（C++17）

```cpp
#include <algorithm>
#include <array>
#include <iostream>
#include <string>
#include <vector>
using namespace std;
int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int T; cin >> T;
    while (T--) {
        int n; string s; cin >> n >> s;
        const int NEG = -1000000000;
        vector<array<int,2>> dp(n + 1, {NEG, NEG}); dp[0][0] = 0;
        for (int i = 0; i < n; ++i) for (int t = 0; t < 2; ++t) {
            if (dp[i][t] < 0) continue;
            char last = i ? s[i - 1 - t] : '\0';
            dp[i + 1][0] = max(dp[i + 1][0], dp[i][t] + (last == s[i]));
            if (i + 1 < n) dp[i + 2][1] = max(dp[i + 2][1], dp[i][t] + (last == s[i + 1]) + (s[i] == s[i + 1]));
        }
        cout << max(dp[n][0], dp[n][1]) << '\n';
    }
}
```
