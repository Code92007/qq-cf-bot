# F · 删除

## 先学什么

建议依次补：排列的相对大小 → 区间 DP → 组合数 → “恰好”与“不超过”的前缀和转换。可以先枚举 n=4 的 24 个排列，严格按“同时删除”模拟每轮。不要一边扫描一边删除，那会改变同一轮后面位置看到的邻居。

## 为什么围绕最大值划分

区间中的最大值比区间内其余数都大，只要它还在，两侧的删除过程互相独立。左右子区间只关心大小关系，不关心具体分到了哪些数字。

区间长度为 len，枚举最大值位置 x 后，左侧长度为 L=x−l。其余 len−1 个数中，任选 L 个交给左边，有 `C(len−1,L)` 种；两边再分别按相对大小计数。这就是每次转移中的组合数来源。

关键在于边界：若一侧是原排列的边界，区间最大值永远不会被删除；若区间两侧都被更大的、尚未删除的数挡住，它最终会在左右内部删空后的下一轮删除。

## 内部区间：用“不超过 t 轮”做状态

定义 `F[l][r][t]`：在区间两侧都有更大的屏障时，区间所有位置在第 t 轮结束前删空的相对排列数，并满足每个已知 a[i]。这些屏障在该区间删空前不会消失。

空区间在第 0 轮已经为空，所以任意 t≥0 的值为 1；t<0 的值为 0。非空区间的 F[...,0]=0。

若最大值放在 x，它恰好在第 t 轮删除，当且仅当左右删空时刻的最大值为 t−1。**这里是最大值恰好为 t−1，不是要求两侧都恰好在 t−1 轮删空。**

所以两侧的方案数为：

```text
F[l][x-1][t-1] * F[x+1][r][t-1]
- F[l][x-1][t-2] * F[x+1][r][t-2]
```

第一项包含“两侧都不晚于 t−1”，第二项减掉“两侧都不晚于 t−2”，剩下的恰好是所需情况。

令 `E[l][r][t]` 表示恰在第 t 轮删空的数量。对所有满足 `a[x]==-1 或 a[x]==t` 的 x，将上式乘 `C(len−1,x−l)` 后求和。再做前缀：

`F[l][r][t] = F[l][r][t-1] + E[l][r][t]`。

## 原排列的边界怎么处理

还要一个状态 `U[l][r]`，用于触及原下标 1 或 n 的区间。这类区间最大值永远不删，因此只枚举 `a[x]∈{-1,0}` 的位置作为最大值。

划分后的每个子区间：若仍然触及原边界，用 U；若已经在内部，被左右更大值夹住，则使用 `F[子区间][n]`，表示不限制具体删空时刻；空区间用 1。

```text
U[l][r] = sum over allowed x:
    C(r-l, x-l) * ways(l,x-1) * ways(x+1,r)

ways(l,r):
    空区间 -> 1
    l==1 或 r==n -> U[l][r]
    否则 -> F[l][r][n]
```

答案是 U[1][n]。按区间长度递增计算：转移只引用更短区间；同一区间内 t 从小到大做前缀。

## 用三元素例子检查语义

a=`[0,1,0]`。中间必须第 1 轮删除，所以它是最小值；两端放 2、3 的顺序任选，答案为 2。

另一个例子 p=`[3,1,2,4]`：第一轮删 1，第二轮删 2。内部区间 `[1,2]` 的最大值 2 的左侧在第1轮删空，右侧原本就是空的。它在第2轮删除，正好说明不能强迫“两侧都在第1轮删空”。

## 正确性与复杂度

按最大值位置划分不会重不漏；组合数唯一决定两侧使用的数字集合；更大边界使两侧相互独立；删空时刻的前缀差精确处理同步删除。因此按区间长度归纳，所有状态都正确。

O(n²) 个区间，每个枚举 O(n) 个时刻和 O(n) 个最大值位置，总时间 O(n⁴)，空间 O(n³)。以题面为准：单组 n≤100，总 n≤400；讲义中的 n≤150 是讲义口径，不应覆盖题面。C++ 中按实际区间长度限制有效时刻，可减少常数。

## 容易错的地方与学习检查

- `a[i]=-1` 表示未知，`a[i]=0` 表示永不删除，不能混为一谈。
- 两个原端点的 a 如果既不是 -1 也不是 0，直接无解。
- 模数为 10^9+7，做减法后要归一化。
- 空区间 t=0 的状态必须为 1，否则单元素内部区间无法在第1轮删空。
- 若全部 a=-1，答案必须是 n!。

先实现慢速枚举，把已知位置随机遮成 -1，再与 DP 比较；这个检验能发现边界状态和组合数漏乘的问题。
