# C · 猫，狗，狗，猫

本文按用户提供的 QOJ 题面截图独立推导。

## 先学什么

先理解 Thue–Morse 序列：从零计数，第 $t$ 项为 $t$ 的二进制中 $1$ 的个数的奇偶性。再把轮到猫的决策看成区间“或”，轮到狗的决策看成区间“与”。

## 结论

将猫记为 $0$、狗记为 $1$。若 $k=1$，取完第 $n$ 颗石子的人固定是序列第 $n-1$ 项。

若 $k\ge2$，胜者是 Thue–Morse 序列的第 $\lfloor n/(k+1)\rfloor$ 项。于是只需计算一个整数的二进制奇偶性。

## 极小极大转移

设 $W_t(s)$ 表示第 $t$ 次操作之前还剩 $s$ 颗时，最终获胜的人。若当前玩家为 $a$，$s\le k$ 时立即取完获胜；否则在 $W_{t+1}(s-1),\ldots,W_{t+1}(s-k)$ 中，只要有一个等于 $a$，就选择它；全部是对手时才会输。

Thue–Morse 每四项为 $a,\bar a,\bar a,a$，其中 $a$ 是第 $\lfloor t/4\rfloor$ 项。令 $L=k+1$，按 $s$ 分块：第零块为 $1,\ldots,k$，第 $q\ge1$ 块为 $qL,\ldots,qL+k$。

**四步引理：**若四步之后的胜者在每个这样的块内恒定，依次做这四步逆向转移，得到的新块序列为 $a,\bar a,f_0,f_1,\ldots$，其中 $f$ 是原来的块序列。

下面说明引理。以“最终由 $a$ 获胜”为真值，四步逆推的算子是“或、与、与、或”。对相邻 $k$ 个位置做“或”，会使每段真值区间向右扩张 $k-1$；做两次“与”，使它收缩 $2k-2$；最后一次“或”再扩张 $k-1$。原真、假连续段长度至少为 $L=k+1$：第一次扩张后假段还剩至少 $2$，真段长度至少 $2k$；中间收缩不会消灭真段，最后扩张也不会合并两段。因此每个完整段的形状保持不变，整体下标右移 $2k+2=2L$。这正是 $q\ge2$ 的两块平移。

边界也可直接检查：第零块当前玩家立刻取完；第一块无论当前玩家取多少，最多剩 $2k$，对手连续拥有下一、下下两步，必能在两步内取完。所以前两块为 $a,\bar a$。这证明引理；它也解释了为什么必须单独处理 $k=1$。

## 为什么是二进制奇偶性

令第 $u$ 组四次操作的块序列为 $f_u$。引理给出

$$
f_u(0)=T(u),\quad f_u(1)=1-T(u),\quad f_u(q)=f_{u+1}(q-2)\ (q\ge2).
$$

候选 $f_u(q)=T(2u+q)$ 满足它：$T(2u)=T(u)$，$T(2u+1)=1-T(u)$，而右侧下标在递推中保持为 $2u+q$。可在有限的最大石子数上从足够靠后的任意块常值边界逆推；游戏至多经过石子数那么多步，边界取值不会影响真实答案。因此 $u=0$ 时确有 $f_0(q)=T(q)$。

## 复杂度

每组 $O(\log n)$ 位运算、$O(1)$ 空间；内建 popcount 可以直接使用。输入达到 $2\cdot10^5$ 组时无需建立博弈 DP 表。

## 完整代码（C++17）

```cpp
#include <iostream>
using namespace std;
int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int T; cin >> T;
    while (T--) {
        long long n, k; cin >> n >> k;
        long long index = k == 1 ? n - 1 : n / (k + 1);
        cout << (__builtin_popcountll(index) % 2 ? "dog" : "cat") << '\n';
    }
}
```
