# H · 数学王国

## 先学什么

建议依次补：期望与方差 → 条件期望 → 吸收马尔可夫链的一步递推 → 对称多项式的前几项 → 模逆元。严格证明部分还会用到有限状态吸收过程的矩存在性，但理解算法不要求先读完整的鞅理论。

一个检查题：若剩余轮数为 T，走一步后剩余轮数为 T'，为什么 `E[T]=1+E[T']`，而 `E[T²]=1+2E[T']+E[T'²]`？如果第二式不熟，先复习平方展开和期望线性性。

## 先给出要计算的量，再解释它们从哪里来

当前各类人数为 s1,…,sk，总人数为 n。定义：

`X = sum(i<j) s[i]*s[j]`，
`Y = sum(i<j<l) s[i]*s[j]*s[l]`。

X 是不同类别的无序人员对数量，Y 是来自三个不同类别的人员三元组数量。最终方差为：

`((n²−2)*X − 2*X² + n*Y) / 3`。

下面从转移推导这个式子，不需要靠小数据拟合猜答案。

## 随机选择一对类别的概率

题目等概率选的是“类别不同的有序人员对”，不是等概率选两种类别。对类别 i、j，人员对数量与 s[i]*s[j] 成正比。

先选无序类别对 `{i,j}` 的概率为 `s[i]*s[j]/X`；再以各1/2的概率进行 `s[i]+1,s[j]−1` 或 `s[i]−1,s[j]+1`。某类别变成0人以后可以直接视为消失，公式仍然成立。

## 第一阶矩：X 每步平均减少 1

固定类别对 i、j。因为其他类别人数不变、si+sj也不变，X 的变化只来自 si*sj：两种方向分别使 X 变化 `−1+si−sj` 或 `−1−si+sj`。平均变化正好是−1。

无论选中哪一对，平均变化都是−1，所以 `E[X'|当前状态]=X−1`。终止时只有一类人，X=0。因此 X 正是剩余轮数的期望。

这是“势能”的具体含义：找一个状态函数，使它每步平均下降固定值，从而把难以直接追踪的时间转换成容易计算的状态量。

## 第二阶矩：平方后多出来了什么

先算同一类别对的平方平均：

`E[X'² | 选中 i,j] = (X−1)² + (si−sj)²`。

按类别对概率加权：

`E[X'²] = (X−1)² + sum(i<j) si*sj*(si−sj)² / X`。

中间那一大项可以只用 X、Y、n 表示。这里把讲义略去的代数展开写出来：

```text
sum(i<j) si*sj*(si-sj)^2
= n * sum(si^3) - (sum(si^2))^2
sum(si^2) = n^2 - 2X
sum(si^3) = n^3 - 3nX + 3Y
```

代入相减得到 `n²X−4X²+3nY`，于是：

`E[X'²] = X²−6X+n²+1+3nY/X`。

问题变成了如何抵消额外出现的 Y/X。

## 再计算 Y 的平均变化

固定 i、j，一项三元乘积如果只包含其中一个类别，两个变化方向平均后抵消；若同时包含 i、j，其他类别人数总和为 n−si−sj，而 si*sj 的平均变化是−1。

所以固定这对时，Y 平均减少 `n−si−sj`。再加权，并注意每个来自三类的乘积会按其中三个类别对各统计一次：

`E[Y'] = Y − 3Y/X`。

这正好可以与上一节的项抵消。令：

`V = ((n²−2)X + X² + nY)/3`，

把三条期望公式代进去，直接得到 `E[V']=V−2X+1`。

## 为什么 V 是轮数平方的期望

设 U 为剩余轮数期望，V 为剩余轮数平方的期望。一步递推应该满足：

`U = 1+E[U']`，
`V = 1+2E[U']+E[V'] = 2U−1+E[V']`。

我们已经找到 U=X，并构造出满足第二式的 V；终止状态上二者都是0。这就是所需的一阶、二阶矩。因此方差是 V−U²，化简得到开头的公式。

为什么可用递推来识别这些矩？对固定 n，状态数有限；从任意状态，都有一个正概率在至多 n−1 步内把所有人变成某个现存类别。这个概率可用一个仅依赖 n 的正数统一下界控制，因此结束时间有几何型尾界，一阶、二阶矩都有限，吸收递推的解唯一。这样就补齐了“满足方程所以就是期望”的依据。

## 实际计算只需一次扫描

完全不需要模拟随机过程，也不需要 O(k³) 枚举三元组。设 e1、e2、e3 为已经读入的类别人数的一、二、三阶乘积和，初始为0。读入新人数 s 时，按以下顺序更新：

```text
e3 += e2 * s
e2 += e1 * s
e1 += s
```

必须从高阶往低阶更新，避免在一个乘积里重复使用新读入的 s。最终 X=e2、Y=e3。全部运算对998244353取模，除以3使用逆元332748118。减法后归一化。

时间 O(k)，额外空间 O(1)。题面输入有 k 个类别，因此应写 O(k)，不要因为讲义习惯把规模统一写 n 就真的循环 n 个人。

## 检查例子与易错点

n=3、各有1人：X=3，Y=1，方差 `((9−2)*3−2*9+3)/3=2`。n=2、各有1人时，恰好一步结束，方差为0。k=1时X=Y=0，直接得到0。

不要在程序里计算 Y/X；它只用于实数推导，X取模后可能为0。最终公式只除以3。中间乘积每一步及时取模，不能先算真实的X²再取模；真实值可能远超64位。
