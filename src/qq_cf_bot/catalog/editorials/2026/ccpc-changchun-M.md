# M · 余镜

## 先学什么

依次补：同余的含义、最大公约数 gcd、回文中心扩展、枚举倍数的筛法。先验证 `x mod m = y mod m` 等价于 `m` 整除 `|x−y|`；再验证同时整除 6 和 10 的数，恰好是 gcd(6,10)=2 的因数。

## 把许多模数合并成一个 gcd

区间取模后是回文，意味着每对关于中心对称的数取模后相等。例如区间 `[1,3,5,7]` 的两对差分别是 6、2。合法模数必须同时整除 6、2，因此必须整除 2，只有 m=2。

一般地，设所有对称差的 gcd 为 g。若 g>0，合法模数就是 g 的所有不小于 2 的因数。因为 a[i] 在 0..M 之间，所以 g≤M，这些因数天然不超过 M，无需再筛掉过大的模数。

若 g=0，说明每对数原本就相等。任意 m=2..M 都可行，贡献为 M−1。不要给 0 使用普通“因数个数”公式。

## 为什么从中心向外走

直接对每个区间重新算全部对称差会达到 O(n³)。同一中心向外扩一格时，只新增最外侧这一对差：

`g = gcd(g, abs(a[left] - a[right]))`。

先令 g=0，利用 gcd(0,x)=x，即可统一处理首对。

需要两类中心：奇数长度中心 c，从 `(c−1,c+1)` 开始；偶数长度中心在 c 与 c+1 之间，从 `(c,c+1)` 开始。这样恰好枚举所有长度至少为 2 的区间，符合 l<r。单个元素不能计入答案。

## 预处理每个 g 的贡献

`count[g]` 表示 g 的不小于 2 的因数个数。枚举模数 d，并给它的所有倍数加 1：

```text
count[0..M] = 0
for d = 2..M:
    for x = d, 2d, 3d, ... <= M:
        count[x] += 1
```

每扩展到一个区间，就累加 `M-1 if g==0 else count[g]`。

例如 `[1,3,2,4,3]`、M=4：区间 `[1,2]`、`[3,4]` 的差均为 2，各贡献 1；区间 `[2,5]` 的差为 0、2，也贡献 1。其余长度至少为 2 的区间贡献 0，总数为 3。

## 复杂度为什么接近平方

筛法时间 O(M log M)，空间 O(M)。扩展次数 O(n²)，每次调用 gcd。保守估计是 O(n² log M)；还可以分析出更紧的 O(n²+n log M) 的 gcd 总工作量：同一中心的非零 gcd 只会变成原值的约数，每次严格变化至少减半，欧几里得算法的非平凡除法代价可沿这一约数链摊还。工程实现直接使用标准整数 gcd 即可。

总空间 O(n+M)，不用保存 O(n²) 个区间。g 一旦变为 1，这个中心之后的贡献全部为 0，可以停止向外扩展。

## 边界与自测

- 所有数相等时，每个区间贡献 M−1，答案是 `n(n−1)/2 * (M−1)`，需要 64 位整数。
- n=1 时没有合法区间，答案为 0。
- 差为 0 不会让先前的 gcd 失效，`gcd(g,0)=g`。
- 模数 1 被题目排除；筛法从 2 开始。

先用三重循环枚举小 n、小 M 的所有区间与模数，再与中心扩展的结果比较，是检查奇偶中心和区间长度边界最直接的方法。
